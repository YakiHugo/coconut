# 🥥 Coconut

把长音视频变成可信、好读、可回源的文字材料。

## 从一分钟试读开始

- 一键打开 Coconut 自写的双语示例，直接体验对照阅读、摘录与笔记；明确标注预置内容，没有虚构音视频或模型结果。重复打开仍保留你的笔记
- 较长文字稿默认进入「连贯阅读」：连续字幕排成可读段落，保留原始 cue、时间戳、笔记与译文归属；缺失或过期译文明示。时间滑轨和摘要页的「原文速览」按真实时间探索内容，不生成章节或虚构重点
- 关联原声后可以「回听这一段」：到段尾暂停，再听一次、接着往后听，或回到之前的播放位置。需要修正或记笔记时进入逐句核对，再返回刚才的段落
- 双语阅读在宽屏并排显示原文和译文，窄屏逐段对照。长稿可用「浏览全文」跨分页定位，包括最后一段；点击会清除当前筛选，不自动播放媒体
- Coconut 图标与暖白、珊瑚色界面统一；文件、原文、笔记和模型调用的原有边界保持明确。公开 Web、轻量服务和高级服务只展示各自实际具备的来源能力

## 一集内容，一个阅读空间

粘贴播客或视频链接，Coconut 按来源选择可用入口。轻量桌面支持公开播客源；通过完整性校验的 macOS 开发包还可直接获取公开 X 单视频的原语言字幕，无需使用者安装 Python。其他视频来源仍需可选高级服务或合法取得的字幕文件；不可用时明确说明，不会静默安装依赖或运行识别。

单集的播放器始终与摘要、原文、双语对照在一起。切换到摘要不再打断声音；摘要引用可回到原片段。双语入口只切换显示，缺少译文时给出下一步，不会自动调用模型。

生成摘要直接在摘要页核对本地工具、全文范围、分批数和额度。共用一个真实请求与同意控件；收起、换集或离开阅读会停止后续批次。已发送的当前批次可能仍完成并消耗额度，进度可备份，继续必须重新确认。

## 桌面内置 X 字幕

- 粘贴公开 X / Twitter 单视频链接后，读取现成原语言字幕并打开同一个阅读空间；不会下载音视频、启动识别或调用 AI。摘要和翻译仍需单独确认
- 打包内置最小运行时，不要求使用者安装 Python、ffmpeg 或识别模型。源码轻量服务和公开静态 Web 不会冒充拥有这个已打包能力
- 仅使用经过限制的公开访客查询；不读取用户账户、Cookie 或浏览器登录。遇到登录要求、限流、访问拒绝、加密字幕或不支持的响应就停止，不切换身份或调用外部下载器
- 最多六小时单视频、每份字幕 1 MiB、20,000 段；来源获取有请求次数、响应大小和超时限制。选择原语言、修改链接、取消或离开会停止旧请求，不会把旧结果加到新来源
- 片段、时间戳、媒体标识、具体字幕轨道和语言依据均保留。“平台提供”不等于人工字幕，也不表示已校对
- 应用使用临时签名（ad-hoc），没有 Developer ID 签名或 Apple 公证；不应绕过操作系统安全警告。真实账户摘要/翻译质量没有因此获得验证

实现与组件来源见 [原生字幕助手](docs/caption-helper-licenses.md)，公开路线证据见 [受限 X 字幕验收](docs/public-x-caption-proof.md)。

## macOS + Web 阅读优先

- Web 无需安装：导入 JSON / SRT / VTT 后，选择同一内容的本地音频或视频，在浏览器中同步回听。媒体不上传；刷新后重新选择文件，文字稿与笔记仍保留
- 含 12 段及以上的文字稿默认打开「连贯阅读」，短稿与自写示例仍可切换阅读方式。摘要与原文速览分别呈现；没有生成过摘要时明确显示未生成，不把摘抄或旧问答伪装成 AI 摘要
- 摘要保留完整发送原文、提供商和引用；原文修改、增加或移除后标记过期。引用可返回原片段；最新摘要不会被后续问答挤出保存记录
- 整篇摘要先展示全文范围、分批数与订阅额度提示；长文最多 64 批原文 + 1 次汇总，所有批次完成后才保存整篇摘要。每批进度随 JSON 备份保留，停止或重启后需重新确认才继续；原文修改后不能沿用旧分批。支持上限及结构验证边界见 [长文摘要计划](docs/long-document-summaries.md)
- 轻量本地服务用 Node.js 22+ 运行，macOS 应用共用同一阅读界面，不要求用户安装 Python、ffmpeg 或识别模型。桌面构建和连接方式见 [本地 AI 工具与 macOS](docs/local-agents-and-macos.md)
- 视频下载、ASR、离线语言模型仍是可选高级服务。轻量服务不假装支持这些能力，也不会自动下载模型或发起推理
- 翻译、平台支持与成本边界见 [来源与 ASR 核查](docs/podcast-sources-and-asr.md)；列出平台不等于已经实现专用导入

## 公开播客来源（轻量桌面版）

- 粘贴公开 RSS / Atom，或公开网页明确声明的订阅源，再选择具体一集；Apple Podcasts 分享链接可通过其公开目录找到发布者 RSS，单集 ID 进一步通过发布者 GUID / 原媒体地址唯一匹配。匹配不到时明确要求手选，不会误取最新一集
- 导入发布者明确关联的定时 JSON / SRT / VTT 文字稿，保留原语言、来源 URL、片段和时间。多语言可明确选择版本；“发布者提供”不等于人工校对
- 小宇宙公开页面只接受明确标注免费、非私密、公开媒体的单集。不会调用隐藏 API、使用 Cookie 或读取会员内容；节目简介不会冒充文字稿
- 回听媒体必须单独点击，重新核对当前单集的 enclosure 后才下载，最多 200 MiB；没有文字稿也可以回听，但不会自动运行 ASR 或模型
- 没有文字稿也能保存[原声项目](docs/audio-library-projects.md)：来源、项目笔记和时间书签可跨刷新、JSON 备份恢复。明确显示无文字稿、无摘要；媒体仍需单独获取，更新后的原声地址可通过重新发现来源恢复
- 原声项目之后可显式补充对应的 JSON / SRT / VTT 或重新检查本集发布者文字稿；仍是同一个项目，保留原有笔记、时间书签与已选媒体。用户笔记不加入 AI 原文，完整记录可随备份恢复
- Spotify 链接使用原发布者 RSS / 合法本地文件作为替代；喜马拉雅和蜻蜓 FM 暂无已验证的直接入口。纯静态 Web 仍用于导入文件阅读，网络来源获取在桌面/轻量服务完成
- 公开来源下载每次解析 DNS 并固定已校验的地址；每跳重定向重检，拒绝内网、访问凭据和私有签名链接。限额、平台边界见 [播客来源导入](docs/podcast-source-import.md)

## 现有阅读与高级处理能力

- 中文简洁界面：正文、搜索与摘录/笔记优先呈现；阅读设置、翻译与 AI、导出和书架备份按需展开，保留完整功能。公开阅读预览明确显示未连接本地服务，启动步骤随时可展开查看

- 独立的添加 / 阅读空间：公开预览优先呈现可用的导入与示例；本地服务连接后才显示视频及媒体处理入口
- 书架整理：每篇可确认移除，真正释放浏览器保存空间。仅在本页保留上一份的撤销与 JSON 导出；再次移除前明确提示旧撤销将结束。刷新或关闭后无法撤销；保存失败会保留书架与恢复副本，不删除后端媒体或任务。
- 阅读导航：书架标题搜索、全文 / 笔记筛选、清除筛选、关闭笔记与返回原片段；“读到这里”标记可跨刷新、备份和重新导入恢复
- 阅读器：JSON / SRT / VTT 导入、全文及笔记搜索、时间回源、本地媒体回放定位、原稿保留的文字修正、整段摘录、片段笔记、JSON 备份与 Markdown 阅读笔记
- 本地处理服务：公开 YouTube / Bilibili / X 视频链接、媒体文件上传、持久任务列表、取消、失败/中断后重试
- 高级视频入口默认仅使用现成字幕：没有匹配字幕就停止，不会自动识别或下载模型。明确取消「仅使用现成字幕」后才允许本地 ASR；也可在允许识别后强制重新转录。命令行使用 --captions-only 获得相同的禁止回退边界
- 已完成的字幕/转录结果和下载音频可在重试时复用；ASR 中途被终止仍需重做识别阶段
- 默认不调用付费模型。明确允许的首次 ASR 可能下载开源模型；运行时间取决于模型和设备

[在线阅读预览](https://yakihugo.github.io/coconut/) 是纯静态页面，不能替你的电脑运行转录。
Web 也可直接选择本地媒体与文字稿对照；AI 连接使用轻量本地服务或 macOS 开发版。当前没有公开云转录后端，也没有跨设备自动同步。

本轮阅读体验改进已进入源码 `main`，桌面版本更新为 `0.6.0`，改动与验证边界见 [0.6.0 发布说明](docs/release-notes.md)。既有 Actions 会在主分支精确提交的全部必需检查通过后，自动发布对应的 macOS 开发包；是否已完成以 [GitHub Releases](https://github.com/YakiHugo/coconut/releases) 为准。CI 测试包不等于已发布版本，公开 Web 预览也不会随桌面发布自动更新。

## 可选高级 Python 服务（macOS / Linux）

需要 Python 3.10+（已测试 3.12）和 Git；视频链接下载音频还需要 ffmpeg。

```bash
git clone https://github.com/YakiHugo/coconut.git
cd coconut
./install.sh
./coconut
```

打开终端显示的 `http://127.0.0.1:8080` 并保持终端运行。安装脚本只创建仓库内的虚拟环境，不修改 shell 配置。
已安装时只需在项目目录运行 `./coconut`；若端口占用，可运行 `./coconut --port 8081`。
公开阅读预览内也有完整启动指引，但它不会跨站连接本地服务。公开预览、本地地址和不同端口有各自独立的浏览器书架；切换前先导出文字稿与笔记，再在新地址导入。备份不包含视频文件。
若 ffmpeg 未安装，先从其官方安装渠道安装；本地字幕导入不依赖 ffmpeg。

服务仅绑定本机回环地址，不要通过反向代理公开暴露。当前不是多用户服务。
处理记录和输入默认放在 `~/.coconut`，可用 `./coconut --data-dir <目录>` 修改。
网络视频限已结束且可确认时长不超过6小时的内容，拒绝直播和频道/合集。上传限 200 MiB，这是首版的资源保护边界，不是模型或平台的官方限制。

## 阅读与数据保存

- 浏览器中的修正与笔记保存在该浏览器的 localStorage 中；清除网站数据会丢失未导出的修改
- 长文字稿每次显示最多 100 段，可前后翻页；继续阅读、AI 引用与播放定位直接打开目标片段所在页。页面内搜索仍检索整篇，AI 的「当前筛选」包含全部匹配片段，不只当前页
- 点击「摘录整段」即可留下原话，不必先写笔记；摘录、笔记和「读到这里」分别保存，取消摘录不会删除笔记
- 摘录视图只看已摘录片段，笔记视图仍只看有笔记的片段；搜索与可选 AI 的当前筛选范围一致
- 「导出阅读笔记」只在点击时生成本篇全部摘录及非空笔记的 Markdown，不受搜索筛选影响；包含时间链接、原文、修正前稿及当前有效的显示译文，不含媒体
- Markdown 用于整理阅读成果；完整恢复请使用 JSON 备份。导出的 JSON 包含修正前文字、时间戳、摘录及笔记，可再次导入
- 处理任务和原始结果保存在本地服务的数据目录；它们与浏览器笔记是两份数据
- 无法读懂已有浏览器数据时，阅读器暂停写入，保留原数据；本次内容应先导出再关闭
- Web 与桌面统一检查术语表、新时间书签和书签时间修正草稿；搜索和已自动保存的笔记不会误报。书签草稿按篇目暂存在当前页，切换篇目或搜索后可返回继续，保存或取消后解除提醒；草稿不包含在 JSON 备份里，刷新或关闭前仍需保存。
- Web 页面存在未保存更改时会请求浏览器的离开提醒；需先有用户交互，移动端或进程终止时可能不出现，不能替代备份。macOS 应用在关闭窗口或退出前检查未保存编辑和进行中的工作，默认继续编辑；明确放弃后才关闭。取消退出不会中断原任务，强制退出或系统终止仍不能保证保留未保存内容
- 本地上传音视频完成后可按时间戳回听原文件；原文件保留在对应任务目录，迁移文字稿不会自动迁移媒体
- 文字稿展示来源类型与识别模型，专有名词仍需回听核对
- 检测到另一个页面更新书架时暂停写入，先导出当前修改再刷新，避免旧页面覆盖新笔记
- 本地服务断开时禁用新处理操作，保留最后任务状态并自动尝试重连；不自动重发导入或订阅请求。提交未确认时先查看任务列表，避免重复导入
- 说话人编号不是真实身份；不让模型根据内容猜人名

## 命令行

```bash
.venv/bin/python transcribe.py 'https://www.youtube.com/watch?v=…'
.venv/bin/python transcribe.py './访谈.mp3' --language zh
.venv/bin/python transcribe.py './字幕.srt' --source-url 'https://www.bilibili.com/video/…'
.venv/bin/python transcribe.py './访谈.mp3' --model small --work-dir ./private-work
```

输出带时间定位的 `.raw.md` 和阅读器可导入的 `.raw.json`。默认输出不会覆盖既有文件；
显式 `-o` 指定输出时会更新该目标。`--work-dir` 保留阶段产物，必须专用于同一份输入和选项。

默认后端为 faster-whisper，small 是初始资源折中，不代表已证明它最适合所有中文材料。
可选 `tiny/base/small/medium/large-v3/large-v3-turbo`。CPU 默认 int8。
有兼容 NVIDIA 环境时可显式指定 `--device cuda --compute-type float16`。
未测过你的 Mac 性能，不提供臆测的 M5 转录耗时。

## 可选增强

- WhisperX：另装 whisperx 后用 `--backend whisperx`，支持独立时间对齐；对齐失败保留 ASR 时间，不丢基础稿
- 说话人区分：WhisperX 路径可用 pyannote；需要自己审阅模型许可并在本机配置相应 Hugging Face 权限
- Claude 润色：另装 anthropic 并在本机配置自己的 API Key 后，显式运行 `polish.py`。这会使用付费 API
- `pt` 默认只导入/转录；第三个参数显式传 `--polish` 才请求付费润色

润色检查完整结束、时间链接和说话人标签是否保留。这不是语义准确性的自动保证。
本地阅读器支持可选订阅 本地 AI 工具与按片段翻译；它们的认证、下载与验收边界见下面说明。当前没有知识图谱。

## 同步回看、多语言与本地 CLI 连接

- 新视频任务可勾选保留本地视频（最多200 MiB），完成后时间按钮优先定位本地播放器，同时保留原站链接；播放时高亮对应字幕，点击“定位正在播放的文字”跳到当前片段
- 原语言支持中、英、日、韩、法、德、西班牙语及自动检测。多语言识别仍由本机 Whisper 运行，不等于所有语言质量都已逐一验证
- 翻译保留每条原文、片段 ID、时间戳和模型来源。译文与原文并排显示、支持搜索和备份；原文修正后旧译文会标为过期
- 本机翻译按32段一批保存，可停止后续批次、刷新后继续。英中使用 Helsinki-NLP 的 OPUS 模型，其余可用语言对从官方 Argos 模型索引准备；语言对不存在时明确报错，不自动跳转到付费服务
- 英中模型需要可选 CPU 依赖：运行 `./install.sh --translation`。勾选允许首次下载后才下载模型，首次准备可能需要约1 GB磁盘；之后离线翻译。译文是离线粗稿，已观察到技术术语错义，不应作为未经核对的正式引用
- 本地 AI 工具默认连接本机官方 Codex CLI 已有 ChatGPT 登录，Claude Code 订阅为可选。每次发送前必须明确勾选同意发送所选文字并使用订阅额度；回答用片段 ID 校验引用，可点回原文，随备份保存
- 连接检测只确认登录方式，不保证额度。额度耗尽、登录过期、CLI不兼容或请求失败时停止；不购买额度、不切换API、不读取或复制令牌、不启动交互式会话
- CLI 调用采用临时目录、无持久会话、禁用执行/浏览器/MCP/插件工具的配置，并拒绝 API Key 认证。当前订阅连接经过协议回归，但尚未在用户账户完成真实推理；需要用户已有合法登录和剩余额度
- Kimi 订阅和 ChatGPT 直接 OAuth 暂未接入。不会把网页登录态或订阅凭据当作第三方 API key

官方接口依据：[Codex 非交互调用](https://learn.chatgpt.com/docs/non-interactive-mode)、[Codex 认证](https://learn.chatgpt.com/docs/auth)、[Claude Code CLI](https://code.claude.com/docs/en/cli-reference)、[Claude 认证](https://code.claude.com/docs/en/authentication)、[OPUS 英中模型](https://huggingface.co/Helsinki-NLP/opus-mt-en-zh)、[Argos 包索引](https://github.com/argosopentech/argospm-index)。

### 可选订阅上下文翻译

“使用订阅翻译当前筛选”会显示片段数与最多请求批次，每32条为一批，把相邻片段一起作为上下文交给所选的官方订阅CLI。
必须重新勾选本次发送与额度同意；没有同意标记的API请求也会被拒绝。不会自动运行、购买额度或切换到API。

- 输出必须完整保留每个ID及顺序；缺失、重复、乱序、空白或源文在请求中被修改时，整批不覆盖已有译文
- 每个完成批次保留原文、时间戳和提供商来源；失败、额度耗尽、取消勾选或按停止按钮会停止后续批次，重试只处理未完成部分
- 精确度仅到原字幕片段范围，不声称译文逐词与声音对齐
- 协议与错误恢复已用假后端验证，尚未用用户真实账户做订阅翻译质量验收；不能把它称为已验证的高质量翻译

本次还对四个技术上下文做了OPUS合并段落与M2M100-418M对照。部分术语改善，但均出现错义或语义遗漏，因此没有切换默认模型，也没有把合并译文伪装成逐条对齐结果。

### 订阅翻译的上下文范围

订阅翻译只发送本次确认的筛选片段。已经翻译的所选片段可能重复发送，作为相邻目标的上下文；不会自动加入筛选外的句子。按原顺序连续片段分组，并按字符数限制拆批，页面显示真实待译数量和请求次数。

批次边界和重试保留少量所选相邻上下文；输出仍只写回本批目标ID。修改目标或依赖的上下文会使译文过期，备份保留这些依赖记录。旧订阅译文没有上下文记录时也会提示重新生成。停止会等待当前批次完成，继续时需重新确认发送和额度。

这些检查避免缺失上下文、片段错配和超范围发送，不保证语义准确；真实订阅翻译质量仍未验收。

### 回归检查与静态发布

每个 PR 和 main 提交由 GitHub Actions 运行 Python 标准库测试、Node/Happy DOM 阅读器回归及静态资源版本检查。CI 不安装或下载 ASR/翻译模型，不使用真实订阅账户；这些回归通过不代表真实模型质量，也不能代替独立的浏览器与原生应用作业。Pages 部署结果与回归测试分别检查。
修改 reader 的 JS/CSS 后运行 `python scripts/reader_assets.py` 更新内容哈希，再用 `python scripts/reader_assets.py --check` 校验；避免部署后 HTML 引用旧缓存。

独立的 `Browser acceptance` 作业使用真实 Chromium 和自制 H.264/AAC 样例检查播放器、阅读、下载和恢复；也支持手动输入公开视频链接，在已有英文字幕门槛下验收原视频。原片、文字稿和浏览器文件不上传公开 artifacts。合成样例结果与原片结果分开报告，详见 [浏览器验收](docs/browser-acceptance.md)。

### 整个书架迁移

书架里的「备份整个书架」一次导出所有文字稿、修正、笔记、摘录、阅读位置和保存的 AI 回答。恢复入口只在浏览器处理 JSON；50 MiB 以内直接读取，更大文件先明确确认再完整读取，不再限制500份。先校验全部内容，再合并到现有书架；相同内容跳过，同标识不同版本分别保留，不删除现有内容。浏览器容量不足时会明确提示只留在当前页，此时先重新备份再关闭。媒体文件仍需原电脑的本地任务，备份不会迁移媒体或订阅登录。完整 JSON 包含译文、AI 记录及依据，导出不受恢复大小硬限制；较大备份需要足够内存，下载后仍需确认文件已保存。SRT / VTT 输入仍限15 MiB，详见 [完整备份恢复](docs/backup-recovery.md)。

### 字幕导出

阅读页可导出整篇 SRT / VTT，保留片段顺序与毫秒时间戳，使用当前修正后的原文，不包含笔记或 AI 回答。可勾选附加当前显示语言的有效译文；缺失和过期译文会跳过并显示实际附加数量。搜索、摘录筛选及当前分页不会缩小导出范围；JSON 仍是保留原稿和完整编辑信息的恢复格式。

WebVTT 的单一说话人 `<v 姓名>` 标注会保留为片段说话人，可使用现有说话人筛选，并随 VTT / JSON 导出恢复。本地文件、发布者播客字幕与 Python 导入使用一致的声部规则；姓名支持空格、class 和 HTML 字符引用。一个 cue 内含多个说话人或部分未标注文字时，保留原时间与一个片段，以 `[姓名] 正文` 分行保留已标注声部；片段不指定单一说话人。此时 VTT 恢复保留可读标签，不恢复原始 voice 标签结构。SRT 没有标准 voice 标注，导出行为不变。
字幕时间按毫秒四舍五入；不足1毫秒或原本零时长的片段导出为至少1毫秒，以免播放器丢弃，原始精度仍保留在 JSON。

阅读页「标题与语言」可为难识别的文件名重命名，也可修正原文语言标记。改名同步到书架搜索和后续下载文件名；取消不写入，保存不改变原始来源、片段时间和笔记。语言标记不会自动发起识别、翻译或 AI 请求。

「跳到时间」支持秒数、分:秒或时:分:秒（可带三位毫秒）。定位会清除筛选并打开目标所在分页；字幕间隙明确提示并选下一段，超出范围不会跳转。这里只定位文字，不会自动播放或访问原站。

「阅读排版」提供标准、大字、大字宽松行距三种原文/译文显示方式。只在当前浏览器保存排版偏好，不改变文字、时间、笔记或 AI 请求；浏览器禁用保存时当前页仍可应用并显示提示。随时选择标准恢复原布局。

本地原声播放器旁提供前后10秒与0.75–2倍速控制。跳转限制在已加载媒体的时长内，不会自动开始播放；速度偏好保存在当前浏览器，切换文字稿或编辑笔记不重置。公开页面没有本地媒体时隐藏这些控件。[2026-10-06 的原片 Chromium 验收](https://github.com/YakiHugo/coconut/actions/runs/37451229607/job/112228013069)验证了原访谈的解码、跳播、字幕高亮、循环和速度恢复；这是该次原片运行的记录，未做完整人工音质/逐字听校。

选择了实际可播放的媒体后，原播放器滚出视口时会出现轻量播放条，可直接暂停、继续、查看当前时间或定位正在播放的原文。它复用同一个播放器，不会另外加载媒体或自动播放；切换内容、移除媒体或回到原播放器后收起。移动端播放条与笔记面板分开，原始播放器仍保留全部原生控制。

本地媒体的每段时间旁可「循环回听此段」，适合核对听不清的术语。只在点击后开始回听；再次点击、停止循环、跳转10秒、点另一时间戳或切换文字稿都会解除循环。媒体未加载、零时长或超出媒体时长的片段不启动；不自动访问原站。循环使用浏览器时间事件，并非逐采样精度。

搜索时可用上一/下一匹配段浏览整篇结果，自动跨100段分页并显示当前序号；两端循环。原文、显示译文、说话人及笔记中的字面匹配会高亮，导入内容始终作为纯文字渲染。清除搜索恢复全文，不改变阅读标记或发送 AI 请求。

AI 面板可导出本篇全部已保存回答为 Markdown，包含问题、提供商、片段定位、完整历史发送原文（包括未被引用的上下文）及当前/过期/未知依据提示。旧记录缺少历史输入时明确标记，不把当前稿冒充当时依据。导出不受筛选影响，不发起模型请求；链接和时间使用当前稿，重要结论仍需回听核对。
更改文字稿的原文语言会同步更新翻译语言选择并撤销尚未使用的发送同意；正在翻译时只完成当前批次，不继续按旧语言请求。只改标题不会覆盖手动选择的翻译原语言。未标明语言时需显式选择，不以历史来源语言覆盖当前标记。

### 本地视频下载恢复

勾选保留视频的任务若已取得文字稿，但视频下载失败或完整标记缺失，任务列表仍可打开文字稿，并提供「重试本地视频」。它复用已完成的文字稿，不重新识别；正在恢复时可取消，取消后仍可重试。恢复成功会清除旧下载警告。已有浏览器笔记不会被后台修改；重新打开带媒体的结果可能作为新版本加入书架，旧版保留。

处理任务定期刷新时保留未变化的按钮和键盘位置。取消、重试或打开结果等待期间，同一任务的操作不会重复发送；失败后可再试。较早的任务列表响应不会覆盖后来的操作结果，刷新也不会把焦点从正在填写的链接或阅读区抢走。

### 收听进度

原声正常播放的位置单独保存在本机，每五秒节流保存，并在暂停、换篇和离页时保存；不改动“读到这里”的手动阅读标记。重新打开后点击“继续收听 mm:ss · 仅定位”，再点击播放器开始，不会自动跳转或播放。少于 15 秒的媒体不记录，前 5 秒及最后 3 秒视为开始/完成。段落临时回听和停止回听保留原主收听位置，明确恢复正常播放后才改记新位置。

本地文件刷新后仍需重新选择。恢复入口要求文件名、大小、修改时间、类型、首中尾各至多 64 KiB 内容指纹及媒体时长匹配；这是有限内容的候选核对，并非全文件一致保证，请核对原声。不同文件不会仅凭同名套用位置。进度保存失败会保留上次记录并提示；进度不包含在文字稿 JSON 导出中。

书架查找切换到「笔记」或「全文」范围后，每份内容最多展示 3 项真实命中预览，并区分原文、片段笔记、项目笔记与时间书签。点击命中可直接到对应原文或笔记，跨页长稿同样适用；书架关键词和筛选保留，不会自动播放或调用 AI。点击文档标题仍按原来的阅读位置打开。
