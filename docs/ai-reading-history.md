# AI 阅读历史：完整保存，按页浏览

## 修复的丢失路径

此前 `retainAnswers` 只留下20则记录（为最新摘要保留一个位置），校验导入、刷新读取和新回答完成都会调用它。45则有效答案经 JSON 校验恢复后只剩20则，导出的旧备份再次导入也会丢记录；较早摘要同样可能丢失。

现在完整保留全部有效答案，沿用现有 JSON schema，不另建归档格式。新问答和摘要只追加；摘要页始终使用最新一则明确标为整篇摘要的记录，不受历史所在页或后续问答影响。此前已删除、且没有另存备份的记录不能从新版中恢复。

## 浏览与导出

- 摘要页的「浏览全部 AI 历史」可直接打开历史；原文页仍可从「翻译与 AI 阅读」进入
- 每页最多10则，最新在前；可浏览较新/较旧页或直接到最新/最早一页。显示总数、页码、记录序号和提供商
- 普通重绘保留当前页；切换文档或新结果到达时回到最新页。翻页、返回、导入和导出均不会调用模型
- Markdown 和本篇 JSON 导出包含全部历史，与搜索、摘录筛选和显示页无关。JSON 用于恢复全部文字、笔记和 AI 结果
- 历史快照保留完整实际发送原文，包括未被引用的上下文。原文变化仍显示过期；整篇摘要还检查是否增加/移除了片段；缺少完整快照的旧记录仍显示未知
- 引用的原片段已不存在时保留 ID 并显示不可定位文字，不把它匹配到其他同位置片段。可用的引用仍能返回当前原文

## 浏览器配额与救援

浏览器 localStorage 容量仍有限。本改动没有扩容，也不自动删除历史来释放空间。每次成功保存才更新持久化检查点；保存失败时原 localStorage 内容不改，新结果保留在内存。历史面板显示已保存数量及仅在此页的数量，摘要页也明确提示未保存。

请在关闭或刷新前使用「导出全部 AI 历史（Markdown）」或「备份本篇全部内容（JSON）」。启动下载不是已经落盘，需确认文件确实保存；导出不清除未保存提示。解除浏览器保存问题后，下一次成功保存会一并写入仍在本页的结果。其他标签页发生写入冲突时仍停止覆盖，先导出本页修改。

完整 JSON 备份没有15 MiB或500篇的硬截断；超过50 MiB时先显示大小与内存风险，需确认后才读取。恢复书架与单篇历史均走相同的大文件审阅流程；JSON解析或浏览器保存失败时保留原有持久记录并提供救援提示。SRT / VTT 的15 MiB字幕限制仍适用。

## 回归边界

`tests/reader-ai-history.test.mjs` 使用自写文字稿及注入回复，覆盖1,205则记录的校验/单篇/书架往返、245则记录分页与跳端、已移除引用、未知依据、整篇范围变更、全部导出、新问答/摘要追加以及配额/权限拒绝后的救援和后续保存。

集成回归另外覆盖完整历史的移除救援、撤销保存失败与重试、含未保存回答时移除失败回滚，以及同编号撤销后丢弃迟到的问答/摘要结果；保留文档身份与移除生命周期防护。单篇与整库的大文件审阅流程还覆盖1,205则历史在配额失败后的完整导出与后续成功保存。

DOM测试验证控件、焦点与导航状态；不代表真实浏览器视觉验收。没有调用真实订阅模型、运行浏览器/媒体验收或消耗用户模型额度。

CI 专用 `tests/ai-history-browser.mjs` 已接入 Browser acceptance，使用245则自写记录检查真实文件选择、10则分页、最早/最新键盘操作后的焦点、不可定位引用、实际 Markdown/JSON 下载、刷新和空白浏览器恢复，以及桌面/390px 手机宽度与自写截图。本地仅检查脚本语法，真实 Chromium 结果以该提交的 CI 为准。
