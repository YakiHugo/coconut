# 阅读外观

在原有「阅读设置」里调整；连贯阅读时入口仍是「信息与设置」。不增加常驻工具栏。

- 阅读排版：标准、大字、大字与宽松行距。标准保留现有原文、译文与段落的默认字号；大字和宽松使用同样的正文大小，宽松增加行距。摘要和 AI 回答也跟随大字设置。
- 正文宽度：随窗口，或适合长读的窄栏。窄栏限制正文每行长度，保留完整双语对照；不会压缩笔记编辑器、播放器或页面工具。小屏仍自动逐段对照。
- 页面外观：明亮、深色、跟随系统。新用户默认明亮，即使系统处于深色；明确选择跟随系统后，才会随系统外观实时变化。深色使用暖灰底、珊瑚色重点和一致的提示、笔记、设置与弹窗颜色。

设置即时生效，分别保存在本浏览器的小型 localStorage 偏好项中，与文字稿书架分开。刷新与切换篇目后沿用；另一窗口更改颜色或宽度时同步。设置不改原文、译文、笔记、阅读标记、媒体位置，不调用模型或网络。JSON 文档备份不含显示偏好。

浏览器无法读取或保存时会提示；当前页仍可调整。不覆盖无法识别的旧值，也不把仅在本页生效的设置说成已保存。选择「标准」「随窗口」「明亮」恢复原默认布局。

## 验证范围

- Node / HappyDOM：默认与有效／损坏偏好的恢复、系统颜色变化、旧版媒体查询事件、存储读写失败、跨窗口变化、原文／草稿／选区／媒体实例保持，以及设置不写书架。
- `tests/reading-appearance-browser.mjs` 是 CI 专用真实 Chromium 验收。使用自写双语字幕和合成音频，要求真实 IndexedDB 就绪，核对持久记录、刷新、系统外观切换、正文和控件对比度、320/390px 溢出、44px 新控件、真实 Tab 焦点、笔记及提问弹窗，并输出仅含自写内容的截图。
- 本地语法与 DOM 检查不能代替真实浏览器视觉验收；是否通过以候选精确提交的 CI 结果为准。该验收不使用用户媒体、账户或模型额度。
