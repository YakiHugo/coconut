# Coconut 0.7.0 · macOS 开发版

## 这次可以直接体验什么

- 书架改为按文档保存到本机 IndexedDB，普通修改不再重写整库。首次升级保留完整旧存储并核验后才开放编辑；不同窗口可分别修改不同文档，同一文档的过期修改会明确报冲突。发生冲突后，当前窗口的其他文档修改也可能暂时无法保存；请先导出本窗口各篇未保存内容，再刷新读取最新数据。
- 批量导入 JSON、SRT、VTT，逐份显示保存、已有、失败或跳过的结果。坏文件不影响其他成功内容；保存失败会停止后续读取，支持重试和完整备份。
- 大书架分页显示，全文与笔记搜索分批处理并显示进度，查完全部内容后再展示结果。完整短语可以跨连续字幕片段查找；不会因为分页而遗漏内容。
- 本地音视频可以先保存为原声项目，再补充文字稿。支持字幕与当前原声的时间偏移校准和试听，不改字幕时间、字幕导出或原站链接。媒体文件仍需保留，刷新或重启后重新选择。
- 新增跨书架「我的笔记与摘录」，汇总片段摘录、笔记、项目笔记和时间书签，返回原位置后可继续之前的查找。Markdown 可导出所选篇目的全部记录；完整恢复仍使用 JSON。
- 缺失译文可自己填写，已有译文可逐条人工核对或修正，保留来源与核对依据；原文或相关依据变化后会重新提示过期。人工标记不代表翻译质量已经验证。
- 「跟随原声」默认关闭，开启后在播放时跟随当前原文并跨阅读页；手动滚动、搜索或编辑会暂停跟随。新增窄栏、深色和跟随系统外观，显示偏好独立保存。
- 从段落直接提问时先核对发送范围；保存全部有效 AI 历史及其依据，不再按历史条数自动删除。新增的阅读、整理和导出操作不需要调用模型。

## 升级、备份与恢复

升级前请在旧版本导出「备份整个书架」，确认下载文件确实保存；升级后有新修改时，再用新版导出一份最新书架 JSON。备份不包含音视频文件、账户登录或未提交的编辑草稿。

首次迁移不会删除或改写原来的 localStorage 书架，并额外保留原始快照。迁移后的新修改保存在 IndexedDB，不会写回旧书架。因此，退回 v0.6.0 只会看到迁移前的旧书架，无法读取新版新增或修改的内容。保留旧应用不等于数据可以无损降级。不要在旧版继续编辑同一个资料库；旧版改写后，新版会停止写入并要求恢复处理，不会自动合并两份数据。

正常恢复请使用新版的「恢复书架备份」导入完整书架 JSON：相同内容跳过，不同修改版本分别保留。超过 50 MiB 的 JSON 会先确认再读取；这不是无限容量保证。SRT/VTT 仍有单文件 15 MiB 限制。

若启动迁移失败，请保留原有网站数据和应用资料目录，下载页面提供的原始数据；数据库仍可打开时，也下载完整存储恢复文件。这些技术恢复文件不能直接当作普通书架备份导入。不要为了重试而清空存储。若编辑后保存失败，请使用「导出未保存文档备份」，保存本窗口所有待保存内容并确认文件已落盘；未提交表单草稿需另行保留，再关闭或刷新。

## 验证范围与边界

发布以最终精确提交的回归、真实浏览器、公开来源和原生 macOS CI 结果为准。本地单元测试不能代替实际浏览器、打包应用或下载落盘验收。浏览器与原生验收使用自写内容、预置响应和合成音频，不代表真实模型输出质量已验证。

真实 Codex / Claude Code 账户的模型调用与输出质量尚未验收。Codex / Claude Code CLI 仍需在本机单独安装、登录；每次发送前确认原文范围与订阅额度。桌面发布不表示公开 Web 预览同步更新。

IndexedDB 仍受磁盘与浏览器配额限制，启动仍需在内存中载入并核验完整书架。分批搜索不保证每一帧都流畅，单篇极长文字稿的索引和搜索仍可能暂时阻塞。

## 下载与安装

以 [GitHub Releases](https://github.com/YakiHugo/coconut/releases) 实际出现的 `v0.7.0` 工件为准。发布包含 Apple Silicon（arm64）和 Intel（x64）ZIP，以及 SHA256SUMS.txt；本说明不是发布完成的凭证。

这是 ad-hoc 签名开发版，具有资源封印，但没有可信 Developer ID，也未公证。文件名继续使用 `-unsigned.zip`，与现有更新器兼容；这不代表 Gatekeeper 信任。不要绕过 macOS 安全警告。现有更新器需明确启用开发版预发布检查，下载后由用户确认安装。详见[桌面更新说明](desktop-updates.md)。
