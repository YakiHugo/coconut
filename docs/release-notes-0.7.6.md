# Coconut 0.7.6 · macOS 开发版

本轮桌面目标版本为 0.7.6。以下为本版本源码的改进；实际发布与下载以 GitHub Releases 为准，本文不表示构建、验收或发布已完成。已交付的 v0.7.5 下载包不包含以下新增功能。

## 相比 0.7.5 的改进

- 手动修正说话人标签：先预览，再修改单个原片段或整篇同标签，保留初始标签以便恢复。不改原文、时间或媒体，不自动识别人；整篇范围不受分页和筛选缩小。
- 跨篇精选成果集：从多篇逐条选取摘录和笔记，命名保存、排序、预览并导出仅所选记录的 Markdown。保存的是选取时快照，保留原话、个人笔记、来源、时间与历史标识，不自动追随源编辑。源文稿移除后仍保留证据，不根据相似文字猜测回源。完整恢复使用成果集或书架 JSON 备份。
- 手动章节目录：在有文字稿的项目按原 cue 设置章节标题，目录按完整原文顺序排列。支持改名、删除、显式重定位、上一章／下一章以及返回跳转前阅读位置；无媒体也能使用。缺失 cue 保留并明确标识，不按最近时间猜位置。导航不自动播放，也不覆盖“读到这里”。

以上阅读、查找、查看历史和复制操作不调用模型；说话人修正、成果集与章节也不调用模型。既有能力见 [0.7.5 历史发布说明](release-notes-0.7.5.md)。

## 使用边界

说话人标签是人工修改的文字标签，不是身份识别或声纹判断。涉及说话人的旧摘录、翻译或 AI 历史保留原依据并按已有规则显示变化，不改写历史引文。

成果集明确仅包含逐条选中的记录，不等于导出所有来源全文或整个书架。Markdown 是阅读成果，不能恢复集合；集合 JSON 使用既有 coconut-library version 1 envelope，应从「恢复书架备份」导入。集合没有媒体、AI 阅读、翻译或普通正文阅读入口。保存失败时保留内存内容、重试与恢复下载；发起下载不等于文件已落盘，也不表示本地保存成功。

章节是当前稿的阅读路标，不是 AI 摘要，也不是时间书签或自动视频分章。原文、说话人或译文修正不会删除同 cue 的章节；缺失章节只能明确重定位，不自动绑定另一篇。真正替换全文不会偷偷继承旧章。TXT、Markdown 和 SRT/VTT 都不能替代完整 JSON 备份。

## 升级、备份与恢复

升级前导出并确认保存「备份整个书架」的完整 JSON；升级后有新修改时，再导出新版备份。备份不包含音视频文件、账户登录或未提交的编辑草稿。

成果集新增显式 reading_collection 书架条目类型，仍使用既有数据库和 version 1 备份封套。0.7.5 不支持这类条目：含集合的单独或混合备份会被拒绝；在同一个浏览器资料库中，旧版 legacy／IndexedDB 启动也可能因一个集合条目而拒绝打开整个书架。已验证该失败会保留原库，支持版本可重新打开；这不是允许安全降级的承诺。请使用支持成果集的新版恢复，保留原始备份，不要为了让旧版打开而清数据。

0.7.5 的验证投影、JSON 文档导入和书架恢复会丢弃 original_speaker 初始标签依据和 reading_chapters 章节，但保留当前 speaker 标签、有效 exact_excerpts 和 exact_excerpt_notes。没有集合条目时，0.7.5 的普通书架加载／保存可保留未知顶层章节字段；但 segments 会重新规范化，嵌套的 original_speaker 仍会丢失，不能再据此恢复初始标签。未知字段保留不代表完整降级兼容。

更早的 0.7.4 JSON 导入／书架恢复还会丢弃 exact_excerpt_notes，但保留有效的 exact_excerpts；不支持精确摘录的更早读者也会丢弃 exact_excerpts。请保留未经旧版处理的原始 JSON，用支持所有字段的新版导入和恢复。

书架继续使用 IndexedDB。旧 localStorage 快照不会同步新版修改，v0.6.0 无法读取新版新增或修改的内容。不要在旧版继续编辑同一资料库，也不要为了重试而清空存储；原始技术恢复文件不能直接当作普通书架备份导入。超过 50 MiB 的 JSON 先确认再读，不代表无限容量；SRT/VTT 仍限单文件 15 MiB。

保存失败时，使用「导出未保存文档备份」保留本窗口所有待保存内容并确认落盘；未提交表单草稿需另行保留，再关闭或刷新。过期写入不会覆盖较新文档，其他独立文档仍可自动保存，全局未保存警告与关闭保护继续有效。

## 验证与下载

以最终精确提交的回归、真实浏览器、公开来源与原生 macOS CI 为准；发布后须核对对应 v0.7.6 的 Apple Silicon（arm64）、Intel（x64）ZIP 和 SHA256SUMS.txt。本说明不构成发布或验证完成凭证。

尚未在用户自己的 Mac 上验收安装与升级；真实 Codex / Claude Code 账户的模型调用与输出质量尚未验收。CLI 仍需单独安装和登录。CI 使用自写内容、预置响应或合成媒体的场景不代表真实模型质量；桌面发布也不表示 Web 预览同步更新。

这是具有资源封印的 ad-hoc 签名开发版，没有可信 Developer ID，也未公证。文件名保留 -unsigned.zip，与现有更新器兼容，不代表 Gatekeeper 信任。不要绕过 macOS 安全警告。接收开发版更新需要明确启用预发布检查，安装仍须用户确认。详见[桌面更新说明](desktop-updates.md)。
