# Coconut 0.7.7 · macOS 开发版

本轮桌面目标版本为 0.7.7，重点是双语摘录与阅读往返。实际发布与下载以 GitHub Releases 为准；本文不表示构建、验收或发布已完成。已交付的 v0.7.6 下载包不包含以下新增功能。

## 升级前先备份

导出并确认保存「备份整个书架」的完整 JSON；升级后有新修改时，再导出新版备份。备份不包含音视频文件、账户登录或未提交的编辑草稿。

新版双语摘录使用 exact_excerpts v2。0.7.6 会拒绝这类记录，包括成果集中的双语摘录：JSON 导入和书架恢复会被拒绝，同一浏览器资料库的 legacy／IndexedDB 启动也可能因此拒绝打开整个书架。实际 0.7.6 模块检查确认拒绝时保留原数据，支持版本可重新打开完整记录；这不代表降级兼容。请保留未经旧版处理的原始 JSON，用支持 v2 的新版打开和恢复，不要为了让旧版打开而清数据。

## 相比 0.7.6 的改进

- 双语精确摘录：在同一个原文窗口内分别选择原文和已保存译文，再明确确认两侧对应；宽屏并排、窄屏上下对照，个人笔记独立保存。保留摘录时的文字、语言与来源，后续修改不会改写历史；书架搜索、成果集、Markdown 和 JSON 可保留所选双语内容。配对不是自动逐字对齐，也不代表译文已核对或准确。
- 搜索后继续阅读：可以返回搜索前的位置，或从当前命中继续连贯阅读；清除筛选保留当前原片段，不再跳回开头。这些往返只在本页，不覆盖手动“读到这里”。
- 段旁回看摘录：从原文旁的「摘录」入口查看历史原话与所选译文、展开来源、补写个人笔记，再返回原处，保留搜索、分页与阅读方式。来源变化明确标为历史关联，不把旧摘录当作当前原话。
- 章节融入正文：已有手动章节标题出现在连续、逐句与双语阅读中；同一自然段可区分多个章节起点，分页与搜索显示实际所属章节。不自动编章，不改变原文字串或播放器范围。
- 字幕编码恢复：本地 SRT / VTT 直接读取合法 UTF-8，以及带 BOM 的 UTF-8、UTF-16 LE / BE；无法完整解码时先选择编码并核对预览，再明确导入。支持浏览器可用的 GB18030 / GBK、Big5、Windows-1252 和 UTF-16，不猜编码、不用替换字符掩盖坏字节。批量导入可跳过当前文件或停止剩余文件，原声项目补字幕共用此入口。

这些操作不调用模型，也不自动播放媒体。字幕原始字节只在本次导入中暂存，不上传或持久保存；JSON 文字稿仍使用 UTF-8，整书架 JSON 使用单独的恢复入口。字符保留不代表所有字体都能显示：验收环境对部分扩展汉字（如 U+20000）缺字，文字内容与导出恢复的码点保持不变。

## 保存与恢复边界

本版没有新增数据库或书架备份协议。完整恢复仍使用 JSON；Markdown、TXT、SRT / VTT 不能代替备份。旧版本对成果集、章节和历史依据的其他限制见 [0.7.6 历史发布说明](release-notes-0.7.6.md)，双语记录的具体边界见 [双语精确摘录](bilingual-excerpts.md)。

书架继续使用 IndexedDB；旧 localStorage 快照不会同步新版修改，v0.6.0 无法读取新版新增或修改的内容。不要在旧版继续编辑同一资料库，不要为了重试而清空存储；原始技术恢复文件不能直接当作普通书架备份导入。

保存失败时，用「导出未保存文档备份」保留本窗口所有待保存内容并确认落盘；未提交表单草稿需另行保留，再关闭或刷新。过期写入不会覆盖较新文档，其他独立文档仍可自动保存，全局未保存警告与关闭保护继续有效。点击下载不等于文件已落盘或本地保存成功。

## 验证与下载

发布后核对 v0.7.7 的 Apple Silicon（arm64）、Intel（x64）ZIP 与 SHA256SUMS.txt。以最终精确提交的回归、真实浏览器、公开来源与原生 macOS CI 结果为准；本说明不构成发布或验证完成凭证，桌面发布也不表示 Web 预览同步更新。

尚未在用户自己的 Mac 上验收安装与升级；真实 Codex / Claude Code 账户的模型调用与输出质量尚未验收。CLI 仍需单独安装和登录，自写内容、预置响应与合成媒体不能证明真实模型质量。

这是具有资源封印的 ad-hoc 签名开发版，没有可信 Developer ID，也未公证。文件名保留 -unsigned.zip，与现有更新器兼容，不代表 Gatekeeper 信任。不要绕过 macOS 安全警告。接收开发版更新需要明确启用预发布检查，安装仍须用户确认。详见[桌面更新说明](desktop-updates.md)。
