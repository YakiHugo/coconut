# Coconut 0.5.0 · macOS 开发版

## 这次可以直接体验什么

- 连贯阅读：较长文字稿默认把连续字幕排成段落，按实际时间浏览。原文与已有有效译文可以一起读；缺失、过期或待核对译文仍明确标注。段落排版保留每个原始 cue、时间戳和说话人，不生成章节，也不改写原话。
- 整段回听：关联对应原声后，点击「回听这一段」，到段尾自动暂停。可以再听一次、接着听后面，或回到之前的播放位置；不会因为打开文字稿就自动下载或播放媒体。
- 核对后继续阅读：从段落进入逐句修正、摘录或笔记，再回到刚才的段落与阅读位置。笔记、原文身份和既有书签仍随 JSON 备份保存。
- 手机首屏：品牌、书架和添加入口合并为一排，成功导入提示更紧凑，给第一段完整原文与译文留下空间。正文大小和分组不变，错误与未保存警告保持醒目。

## 验证范围与边界

阅读流程的浏览器验收使用自写文字、预置译文和本地生成的 WAV，覆盖连贯阅读、手机首屏、逐句核对后的返回、笔记保存、实际音频解码、整段回听与自动暂停。预置译文和模拟响应只验证界面及状态流程，不是模型效果证明。

真实 Codex / Claude Code 账户的模型调用与输出质量尚未验收。本次版本不会自动调用模型；官方 CLI 仍需在本机单独安装、登录，每次发送前确认原文范围与订阅额度。桌面版本更新不表示公开 Web 预览已经同步。

## 下载与安装

沿用既有 Actions → GitHub Releases 管线：主分支精确提交的回归、浏览器、公开来源与原生 macOS 构建检查通过后，才发布对应的 Apple Silicon（arm64）与 Intel（x64）ZIP，并附 SHA256SUMS.txt。以 [GitHub Releases](https://github.com/YakiHugo/coconut/releases) 中实际出现的 `v0.5.0` 工件为准；此说明本身不是发布完成的凭证。

这是 ad-hoc 签名的开发版，具有资源封印，但没有可信 Developer ID，也未公证。文件名继续使用 `-unsigned.zip` 以兼容既有更新器；这不代表 Gatekeeper 已信任它。不要绕过 macOS 安全警告。签名和更新限制见 [桌面更新说明](desktop-updates.md)。

没有修改更新权限、签名身份、数据格式或发布准入条件。更新前仍建议导出重要文字稿与笔记；备份不包含音视频文件。
