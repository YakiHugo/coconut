# Coconut 0.7.9 · macOS 开发版

本轮桌面目标版本为 0.7.9，重点是宽幅书架查找、直接切换阅读语言和浮动原声栏后退10秒。实际发布与下载以 GitHub Releases 为准；本文不表示构建、验收或发布已完成。已交付的 v0.7.8 下载包不包含以下新增功能与修复。

## 升级前先备份

导出并确认保存「备份整个书架」的完整 JSON；升级后有新修改时，再导出新版备份。备份不包含音视频文件、账户登录或未提交的编辑草稿。

从 0.7.7 起双语摘录使用 exact_excerpts v2；本版沿用它，不新增 schema。0.7.6 会拒绝这类记录，包括成果集中的双语摘录：JSON 导入和书架恢复会被拒绝，同一浏览器资料库的 legacy／IndexedDB 启动也可能因此拒绝打开整个书架。实际 0.7.6 模块检查确认拒绝时保留原数据，支持版本可重新打开完整记录；这不代表降级兼容。请保留未经旧版处理的原始 JSON，用支持 v2 的新版打开和恢复，不要为了让旧版打开而清数据。

## 相比 0.7.8 的改进

- 宽幅书架查找：点「查找书架」打开独立宽幅面板，窄屏使用全屏；搜索、范围与关闭入口固定在顶部，结果独立滚动。保留每页40篇、直接页码跳转与每种语言的上一处／下一处。选中命中后可「返回书架结果」，继续原搜索词、范围、页码及语言命中；取消、Escape、反复打开或缩放不会提交草稿或改动已存阅读位置。过期或被替换的结果不会按旧标识猜位置；整理与备份仍在普通书架工具中。搜索会话不写入备份或持久存储，译文仍只搜索全部语言当前有效的已存内容，不保证译文语义正确。详见[跨书架查找译文](library-translations-search.md)。
- 直接选择阅读语言：正文旁常驻的「阅读显示」可选「仅原文」或已有译文语言，无需展开 AI 设置；摘要与无文字稿的原声项目不显示它。缺失或过期译文明示，不把过期文字当作有效译文。切换保留当前正文阅读位置、分页、未提交笔记与输入法状态，以及同一个播放器、速度、播放／暂停、跟随与片段循环；不修改 AI 任务目标或发送同意。在途译文仍按原任务目标保存，不抢回已重新选择的显示语言。具体语言沿用既有保存字段；「仅原文」的隐藏选择只在本页，刷新后连贯阅读仍可能按原规则自动显示已有译文。切换语言会清除旧的双语导出勾选，需重新确认。
- 浮动原声栏后退10秒：向下阅读时可直接点「后退10秒」，无需返回顶部播放器。只操作已关联且可用的同一个播放器，跳转不越过媒体起点；暂停时仍暂停，播放时继续播放，速度与音量保留。后退退出当前片段循环或有边界的段落回听，回到普通播放；窄屏仍保留跟随状态与定位原文入口。修复片段循环在媒体时钟量化及跳转完成前继续播放时被误当成外部跳转的问题，后续新的外部跳转仍会解除循环。循环基于媒体事件，不承诺逐采样精度；无可用媒体时不会下载或启动播放器。

这些操作不调用模型。书架查找与阅读语言切换不自动定位或播放媒体；后退10秒是明确的播放器跳转，不会上传本地媒体。切换阅读显示不会撤回已经发送的模型请求；已有任务仍可能继续并消耗额度。JSON 文字稿仍使用 UTF-8。字符保留不代表所有字体都能显示，部分扩展汉字（如 U+20000）的字体缺字边界仍适用。

## 保存与恢复边界

本版没有新增数据库或书架备份协议。完整恢复仍使用 JSON；Markdown、TXT、SRT / VTT 不能代替备份。字幕导入、原声关联、原文纠错及译文导出见 [0.7.8 历史发布说明](release-notes-0.7.8.md)；既有双语摘录、阅读往返与编码恢复见 [0.7.7 历史发布说明](release-notes-0.7.7.md)；更早版本限制见 [0.7.6 历史发布说明](release-notes-0.7.6.md)，双语记录边界见 [双语精确摘录](bilingual-excerpts.md)。

书架继续使用 IndexedDB；旧 localStorage 快照不会同步新版修改，v0.6.0 无法读取新版新增或修改的内容。不要在旧版继续编辑同一资料库，不要为了重试而清空存储；原始技术恢复文件不能直接当作普通书架备份导入。

保存失败时，用「导出未保存文档备份」保留本窗口所有待保存内容并确认落盘；未提交表单草稿需另行保留，再关闭或刷新。过期写入不会覆盖较新文档，其他独立文档仍可自动保存，全局未保存警告与关闭保护继续有效。点击下载不等于文件已落盘或本地保存成功。本版不会记住或恢复本地媒体的磁盘访问权；刷新后仍须重选媒体，书架 JSON 不能代替音视频文件。
