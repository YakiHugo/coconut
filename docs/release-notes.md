# Coconut 0.7.5 · macOS 开发版

本轮桌面目标版本为 0.7.5。以下为本版本源码的改进；实际发布与下载以 GitHub Releases 为准，本文不表示构建、验收或发布已完成。v0.7.4 下载包不包含以下新增功能。

## 相比 0.7.4 的改进

- 精确摘录可添加、修改和删除个人笔记；笔记与不可变的历史引文分开保存，完整 JSON 备份保留笔记，笔记本 Markdown 将其单列。保存成功仍以实际持久化回执为准。
- 书架可搜索已保存的精确摘录及其个人笔记；结果明确区分历史引文与当前原文。缺失或变化的来源不会按相似文字猜测定位。
- SRT/VTT 导入保留有效字幕时，对能够识别的、被跳过的损坏块显示逐文件警告，帮助发现部分导入。这不是对所有损坏字幕的完整验证；警告属于本次导入结果，不作为文档元数据恢复。
- 输入片段笔记时复用未变化的书架来源元数据，减少重复扫描和书架刷新，保留输入框、光标与组合输入。验证依据是确定性的扫描／渲染次数，不承诺真实浏览器或用户设备的输入延迟。
- 可跨书架分页与筛选选择文档，导出所选文档的 JSON 备份；包含本页已生效的原文、修正、批注、译文和已保存 AI 历史及依据，可用「恢复书架备份」恢复。使用既有 coconut-library version 1 格式，只包含所选子集，不等于备份整个书架。

以上阅读、查找、查看历史和复制操作不调用模型；个人笔记、导入诊断和所选备份也不调用模型。既有功能见 [0.7.4 历史发布说明](release-notes-0.7.4.md)。

## 使用边界

精确摘录仍只支持一个显示段落中的连续原文；时间精度到原字幕片段，不是逐词对齐。个人笔记不会改写历史引文。书架历史搜索不会发起新的摘要、翻译或问答。

所选备份保留已生效的文档内容，包括仍待本地保存的修改；不包含媒体文件、账户登录或未提交的编辑草稿。下载提示只表示已发起下载，请确认文件实际保存；导出不等于本地保存成功，不清除未保存警告。选择是当前会话状态，重载不会恢复选择。完整升级备份仍应使用「备份整个书架」。恢复跳过相同内容，分别保留不同修改版本，不替换整个资料库。

TXT、Markdown 和 SRT/VTT 都不能替代完整 JSON 备份。同任务原声恢复的本地绑定不通过普通 JSON 备份恢复。

## 升级、备份与恢复

升级前导出并确认保存「备份整个书架」的完整 JSON；升级后有新修改时，再导出新版备份。备份不包含音视频文件、账户登录或未提交的编辑草稿。

本版新增可选的 exact_excerpt_notes 个人笔记字段，与 exact_excerpts 历史引文分离；不是数据库或备份版本迁移。0.7.4 的验证投影、JSON 文档导入和书架恢复会丢弃 exact_excerpt_notes，但保留有效的 exact_excerpts 引文。0.7.4 普通书架加载／保存可以保留未知字段，却不能查看或管理这些个人笔记，因此不能据此推断完整降级兼容。更早、不支持精确摘录的旧版 JSON 导入／书架恢复还会丢弃 exact_excerpts。请保留未经旧版处理的原始 JSON，并用支持相应字段的版本恢复。无效或不支持的摘录／个人笔记记录会被拒绝，不会静默丢弃。

书架继续使用 IndexedDB。旧 localStorage 快照不会同步新版修改，v0.6.0 无法读取新版新增或修改的内容。不要在旧版继续编辑同一资料库，也不要为了重试而清空存储；原始技术恢复文件不能直接当作普通书架备份导入。超过 50 MiB 的 JSON 先确认再读，不代表无限容量；SRT/VTT 仍限单文件 15 MiB。

保存失败时，使用「导出未保存文档备份」保留本窗口所有待保存内容并确认落盘；未提交表单草稿需另行保留，再关闭或刷新。过期写入不会覆盖较新文档，其他独立文档仍可自动保存，全局未保存警告与关闭保护继续有效。

## 验证与下载

以最终精确提交的回归、真实浏览器、公开来源与原生 macOS CI 为准；发布后须核对对应 v0.7.5 的 Apple Silicon（arm64）、Intel（x64）ZIP 和 SHA256SUMS.txt。本说明不构成发布或验证完成凭证。

尚未在用户自己的 Mac 上验收安装与升级；真实 Codex / Claude Code 账户的模型调用与输出质量尚未验收。CLI 仍需单独安装和登录。CI 使用自写内容、预置响应或合成媒体的场景不代表真实模型质量；桌面发布也不表示 Web 预览同步更新。

这是具有资源封印的 ad-hoc 签名开发版，没有可信 Developer ID，也未公证。文件名保留 -unsigned.zip，与现有更新器兼容，不代表 Gatekeeper 信任。不要绕过 macOS 安全警告。接收开发版更新需要明确启用预发布检查，安装仍须用户确认。详见[桌面更新说明](desktop-updates.md)。
