# Coconut 0.6.0 · macOS 开发版

## 这次可以直接体验什么

- 更顺畅地读长文字稿：播放时复用片段索引与段落范围，不再随进度刷新反复重建整篇。阅读页收起低频信息，手机上给完整原文与译文留下更多空间；播放控制和保存提示不会互相遮挡。
- 从书架直接找到原话：全文或笔记搜索显示带出处的命中片段，点击回到对应句子、项目笔记或时间书签，保留搜索条件。
- 继续上次收听：每篇单独记录播放位置，关联匹配媒体后可明确选择「继续收听」。只定位，不自动播放；临时段落试听不会覆盖正常进度。
- 误删后可以撤销：从书架移除内容后，本页保留最近一份恢复副本，可撤销或单独导出。恢复区仅有一个槽位，刷新或关闭后消失；整库备份不包含已经移除的内容，媒体文件也不包含在备份中。
- 保留字幕里的说话人：WebVTT 的语音标记在文件导入和公开来源字幕入口中保留；同一条字幕的多名说话人保留在文本中，不捏造新的时间戳。修正了打包应用读取这些模块时的加载边界。
- 输入一半也能接着写：未提交的时间书签、书签时间修正和术语表草稿随文档切换保留；移除后撤销也能恢复相应草稿。网页离开和桌面关闭会检查尚未保存的修改。草稿仍在本页内存中，并非已经写入磁盘。

- 更新与退出各自完成：修复两者并发时可能错误解除锁定或让页面无法继续编辑的问题。准备更新时仍可正常编辑；出现新的导入或草稿会暂停安装，取消或失败后的恢复只影响对应操作。

## 验证范围与边界

浏览器验收使用自写文字、预置译文和本地生成的 WAV，覆盖搜索跳转、真实音频解码、收听位置、临时试听、删除与撤销、存储失败、手机布局和草稿保护。原生 macOS 检查覆盖源目录、打包应用与发布 ZIP。预置译文和模拟响应只验证界面及状态流程，不是模型效果证明。

真实 Codex / Claude Code 账户的模型调用与输出质量尚未验收。本次版本不会自动调用模型；官方 CLI 仍需在本机单独安装、登录，每次发送前确认原文范围与订阅额度。桌面版本更新不表示公开 Web 预览已经同步。

## 下载与安装

沿用既有 Actions → GitHub Releases 管线：主分支精确提交的回归、浏览器、公开来源与原生 macOS 构建检查通过后，才发布对应的 Apple Silicon（arm64）与 Intel（x64）ZIP，并附 SHA256SUMS.txt。以 [GitHub Releases](https://github.com/YakiHugo/coconut/releases) 中实际出现的 `v0.6.0` 工件为准；此说明本身不是发布完成的凭证。

这是 ad-hoc 签名的开发版，具有资源封印，但没有可信 Developer ID，也未公证。文件名继续使用 `-unsigned.zip` 以兼容既有更新器；这不代表 Gatekeeper 已信任它。不要绕过 macOS 安全警告。签名和更新限制见 [桌面更新说明](desktop-updates.md)。

没有修改更新权限、签名身份或发布准入条件。更新前建议导出重要文字稿与笔记；备份不包含音视频文件。
