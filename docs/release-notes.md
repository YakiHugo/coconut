# Coconut 0.7.3 · macOS 开发版

## 相比 0.7.2 的改进

- 读到哪里，继续哪里：导入带阅读标记的单篇 JSON 后，直接回到已保存的位置；在连贯阅读、原文和双语之间切换时，保留当前原文位置，不改写手动阅读标记，也不自动播放。
- 选中原文即可「引用原文」：在同一段落内选择连续文字，预览并复制选中文字、标题、原字幕时间范围及可用来源链接。手机窄屏先显示引用预览和复制操作，需要改选时再展开原文。
- AI 历史可以核对当时的依据：普通问答、整篇摘要和段落问答均可展开已有的有效发送快照，逐页查看完整原文，包括后来移除的片段和未被引用的上下文。
- 「我的笔记与摘录」的大书架查找改为分批处理，翻页可复用已经完成的同条件结果；改词、关闭或修改内容后，不显示过期结果，也不截断匹配记录。
- 时间书签编辑与搜索保持一致：修改笔记时保留编辑焦点，离开该条后更新筛选结果；修改时间后同步刷新书架命中预览和书签搜索，并保留未提交的时间编辑草稿。
- 保存失败提示和重试/导出操作会留在当前阅读视口，小屏编辑/播放时也可到达，不抢阅读位置或输入焦点。

以上阅读、查找、查看历史和复制操作不调用模型。此前功能与边界见 [0.7.2 历史发布说明](release-notes-0.7.2.md)。

## 这次功能的边界

- 「引用原文」是临时预览与复制，不会保存为精确文字摘录，也不改动笔记或 JSON 备份。仅支持一个当前显示段落内的连续原文；时间精度到原字幕片段，不代表逐词对齐。剪贴板写入失败时可手动复制预览。
- 历史依据仅展示记录中实际保存的有效快照。缺失快照的旧记录不能补出当时原文；不会用当前稿的来源、说话人或时间冒充历史信息。查看依据不等于验证回答正确。
- 笔记本查找分批让出执行机会，不保证固定响应时间或每帧流畅；完整导出、记录渲染和部分字符串操作仍可能同步耗时。

## 升级、备份与恢复

本次沿用 0.7.0 的 IndexedDB 书架格式。升级前请在旧版本导出「备份整个书架」，确认下载文件确实保存；升级后有新修改时，再用新版导出一份最新书架 JSON。备份不包含音视频文件、账户登录或未提交的编辑草稿。

首次迁移不会删除或改写原来的 localStorage 书架，并额外保留原始快照。迁移后的新修改保存在 IndexedDB，不会写回旧书架。因此，退回 v0.6.0 只会看到迁移前的旧书架，无法读取新版新增或修改的内容。保留旧应用不等于数据可以无损降级。不要在旧版继续编辑同一个资料库；旧版改写后，新版会停止写入并要求恢复处理，不会自动合并两份数据。

正常恢复请使用新版的「恢复书架备份」导入完整书架 JSON：相同内容跳过，不同修改版本分别保留。超过 50 MiB 的 JSON 会先确认再读取；这不是无限容量保证。SRT/VTT 仍有单文件 15 MiB 限制。

若启动迁移失败，请保留原有网站数据和应用资料目录，下载页面提供的原始数据；数据库仍可打开时，也下载完整存储恢复文件。这些技术恢复文件不能直接当作普通书架备份导入。不要为了重试而清空存储。若编辑后保存失败，请使用「导出未保存文档备份」，保存本窗口所有待保存内容并确认文件已落盘；未提交表单草稿需另行保留，再关闭或刷新。

同一文档的过期写入仍不会覆盖较新内容；其他独立文档仍可自动保存，全局未保存警告与关闭保护继续保留。

## 验证范围与边界

发布以最终精确提交的回归、真实浏览器、公开来源和原生 macOS CI 结果为准。本地单元测试不能代替实际浏览器、打包应用或下载落盘验收。浏览器与原生验收使用自写内容、预置响应和合成音频，不代表真实模型输出质量已验证。

尚未在用户自己的 Mac 上验收安装与升级。真实 Codex / Claude Code 账户的模型调用与输出质量尚未验收。Codex / Claude Code CLI 仍需在本机单独安装、登录；每次发送前确认原文范围与订阅额度。桌面发布不表示公开 Web 预览同步更新。

IndexedDB 仍受磁盘与浏览器配额限制，启动仍需在内存中载入并核验完整书架。分批搜索不保证每一帧都流畅，也不消除完整书架载入和索引构建的成本。

## 下载与安装

以 [GitHub Releases](https://github.com/YakiHugo/coconut/releases) 实际出现的 `v0.7.3` 工件为准。发布包含 Apple Silicon（arm64）和 Intel（x64）ZIP，以及 SHA256SUMS.txt；本说明不是发布完成的凭证。

这是 ad-hoc 签名开发版，具有资源封印，但没有可信 Developer ID，也未公证。文件名继续使用 `-unsigned.zip`，与现有更新器兼容；这不代表 Gatekeeper 信任。不要绕过 macOS 安全警告。现有更新器需明确启用开发版预发布检查，下载后由用户确认安装。详见[桌面更新说明](desktop-updates.md)。
