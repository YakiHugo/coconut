# 来源文字与原声的统一流程

有现成字幕不代表音频已保存，也不代表文字准确。新导入的来源稿保留原文，标记为需要对齐；支持来源任务的服务会尝试取得并持久保存对应原声。明确无字幕的视频可沿已有受限媒体接口取得原声，网络或访问拒绝不会被解释为字幕不存在。不会自动启动 ASR、付费校对或翻译。

## 运行范围

持久来源任务和独立对齐使用 `npm start` / `server/main.mjs` 的 standalone 服务。Electron 内置的轻量 `desktop/main.mjs` 尚不启用 `sourceJobs` / 本地转录执行器；不要仅将新 Python 文件加入打包清单就声称桌面包支持它。界面在不支持的连接下保留导入的文字并提示服务能力限制。

## 已有稿对齐

用户显式生成已有稿对齐候选。服务使用当前保存的原声音频和本地 Qwen ForcedAligner，不加载 ASR 或调用文本校对模型。当前只支持已有有界时间片段，不支持无时间全文的自动定位。

输入的原文、cue ID、起止时间不变；新增的逐词时钟必须位于原 cue 范围内且可以映射回文字。超长、越界、缺时钟或不完整映射会报告待核对。候选需显式接入，持久保存原文快照、报告及音频 SHA。原文或音频变化时拒绝旧候选。

完整覆盖率只说明时间候选通过结构校验，不证明转录正确。删减稿、改写稿、不同剪辑、同音错误仍需回听或独立识别核验。`source_text_quality` 保持 `unverified`。没有实现自动质量评分或低质稿自动重转录。

## 说话人

短回应、竞争和重叠声音不能被多数票直接吞并；不能可靠拆分时保留未知。原文字和时间轴不删除。相关回归验证逻辑，不代表真实音频分人准确率通过验收。

## 语气词和翻译

本轮没有覆盖用户本地未提交的口语清理代码。研究结论是先识别换人边界，再保守处理可撤销的阅读层隐藏；回应、否定、数字和不确定范围应保留。AI 翻译仍是独立手动路径，实验前不自动执行。
