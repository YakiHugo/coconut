# Coconut 0.7.8 · macOS 开发版

本轮桌面目标版本为 0.7.8，重点是字幕导入、原文纠错与有效译文的查找和导出。实际发布与下载以 GitHub Releases 为准；本文不表示构建、验收或发布已完成。已交付的 v0.7.7 下载包不包含以下新增功能与修复。

## 升级前先备份

导出并确认保存「备份整个书架」的完整 JSON；升级后有新修改时，再导出新版备份。备份不包含音视频文件、账户登录或未提交的编辑草稿。

从 0.7.7 起双语摘录使用 exact_excerpts v2；本版沿用它，不新增 schema。0.7.6 会拒绝这类记录，包括成果集中的双语摘录：JSON 导入和书架恢复会被拒绝，同一浏览器资料库的 legacy／IndexedDB 启动也可能因此拒绝打开整个书架。实际 0.7.6 模块检查确认拒绝时保留原数据，支持版本可重新打开完整记录；这不代表降级兼容。请保留未经旧版处理的原始 JSON，用支持 v2 的新版打开和恢复，不要为了让旧版打开而清数据。

## 相比 0.7.7 的改进

- 字幕优先关联原声：先导入独立文字稿，再选择对应本地音视频，可把关联保存到同一篇，保留正文、译文、笔记、章节与摘录。重新打开媒体时，即使只找到一篇文字稿候选，也要明确选择使用已有稿件、新建原声项目或取消，不自动合并。关联仅保存文件元数据与首／中／尾有限采样指纹，不是全文件内容相等保证；请核对原声。刷新后仍须重选媒体，不保存媒体字节、磁盘路径或访问权。更换或解除关联需确认，并清除旧校准、媒体时长和收听续点；历史来源快照保留。
- 直接粘贴定时字幕：粘贴 SRT / VTT 后先预览真实片段数、时间、前三段和未识别字幕块，再开始阅读；修改输入、标题或格式需重新预览。只接受完整起止时码，不给普通文字猜时间，不读取剪贴板权限；UTF-8 计量限 15 MiB。同标题与同解析内容的文件导入共用去重，保留已有笔记。保存失败保留本页草稿和文稿，可重试或导出完整 JSON 救援；未提交草稿只在本页，刷新后不恢复。
- 整篇批量纠正原文：区分大小写的字面查找与替换，先逐处核对，再应用所选；跨预览页保留选择，不受阅读筛选或分页缩小范围。保留已有原稿基线，不改写译文、摘要、双语摘录或成果集的历史快照，依赖已变原文的结果按原规则标为过期。本页仅保留最近一批撤销，刷新后不保留；发生后续原文冲突时拒绝覆盖，保存失败可重试或导出完整 JSON 救援。撤销恢复本批前的原文与基线，不覆盖新笔记。
- 跨书架查找译文：检索所有语言的当前有效已存译文，不受当前阅读语言限制；每篇每语言可上一处／下一处翻阅，并定位到可见的实际译文匹配。过期、缺失译文和未提交草稿不参加搜索，不把历史摘录混作当前译文。跳转不覆盖已存阅读位置，也不自动定位或播放媒体；“当前有效”只表示保存的依据未过期，不保证译文语义正确。
- 修复显示译文导出：TXT 与 SRT / VTT 明确勾选后，可附加当前实际显示语言的有效译文，包括连贯阅读自动显示的语言；Markdown 阅读笔记也使用当前显示语言。切换语言或篇目会清除旧勾选，收起译文、摘要或仅原文模式不带出隐藏译文，过期译文不导出。整篇文字与字幕不受分页或搜索缩小范围；历史双语摘录仍保留当时快照，跨书架笔记仍使用各篇已保存语言设置。

这些操作不调用模型，也不自动播放媒体。批量原文应用或撤销会停止后续模型批次并拒绝迟到结果；已发送请求无法撤回，仍可能消耗额度，再次发送需重新确认。字幕与所选本地媒体不因这些操作上传；JSON 文字稿仍使用 UTF-8。字符保留不代表所有字体都能显示，部分扩展汉字（如 U+20000）的字体缺字边界仍适用。

## 保存与恢复边界

本版没有新增数据库或书架备份协议。完整恢复仍使用 JSON；Markdown、TXT、SRT / VTT 不能代替备份。既有双语摘录、阅读往返与编码恢复见 [0.7.7 历史发布说明](release-notes-0.7.7.md)；更早版本对成果集、章节与历史依据的限制见 [0.7.6 历史发布说明](release-notes-0.7.6.md)，双语记录边界见 [双语精确摘录](bilingual-excerpts.md)。

书架继续使用 IndexedDB；旧 localStorage 快照不会同步新版修改，v0.6.0 无法读取新版新增或修改的内容。不要在旧版继续编辑同一资料库，不要为了重试而清空存储；原始技术恢复文件不能直接当作普通书架备份导入。

保存失败时，用「导出未保存文档备份」保留本窗口所有待保存内容并确认落盘；未提交表单草稿需另行保留，再关闭或刷新。过期写入不会覆盖较新文档，其他独立文档仍可自动保存，全局未保存警告与关闭保护继续有效。点击下载不等于文件已落盘或本地保存成功；保存已开始时关闭粘贴字幕弹窗不会撤回写入，保存结果仍在书架。
