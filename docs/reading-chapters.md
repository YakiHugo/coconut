# 手动章节目录

章节是你为当前文字稿设置的阅读路标，不是 AI 自动摘要，也不是精确摘录历史。没有媒体也可使用。标题和备注不会作为原文发送给 AI；原文搜索、摘录搜索和跨篇精选成果集不会把章节当作原话或另一条时间书签。

## 在原文中辨认章节

连续阅读在含有章节起点的段落上方显示你的完整标题、当前原文时间和完整稿片段序号。段内对应的原文 cue 前显示同号小路标，多个章节在同一自然段中仍可区分。只有你实际保存并且起点仍存在的章节会出现；不会根据段落、说话人、时间或搜索结果自动编章。失效章仍在目录中明确保留，不标到相似原文上。

翻到后页时，页首会显示该位置的「所在章节」；逐句、双语和筛选结果在实际起点或所属章发生变化时显示相应标题。「所在章节」不会把页首或搜索命中伪装成章开头。普通段落不反复插入同一标题，未设章的稿件保持原来的阅读布局。

路标仅为展示：自然段分组、cue 顺序、原文字串与分隔符、时间、播放器范围、翻译上下文、问这一段和精确摘录均不改变。标题在原文段落 DOM 外，小编号由 CSS 生成并排除选择，原文 cue 的可访问说明指向对应的实际标题，不用整段原文作为重复标签。创建、改名、重新定位和删除章节只更新这些派生标签，不替换原文节点或播放器；异步保存回执只更新既有保存状态，不重建标题、不夺取焦点或触发滚动。

`tests/reader-chapter-markers.test.mjs` 检查完整源顺序、相同时间、空/长 ID、缺失及重排、双语/搜索往返、跨章精确摘录、保存失败/重试、节点身份和大文档索引。`tests/chapter-markers-browser.mjs` 由现有 CI 浏览器流程运行自写素材，检查桌面与390px的原生选择/剪贴板、可访问树、字体主题和布局截图；本地 DOM 测试不能替代这些浏览器验证。

## 单一数据模型

每篇普通文字稿可以有可选的 reading_chapters 数组；它与文稿一起通过现有保存队列、JSON 和书架备份保存，没有新增数据库或协议版本。旧文稿没有此字段仍然有效，普通 timestamp_bookmarks 与 readingPosition 完全不变。

每项包含稳定 id、用户 title、cue_id、建立或显式重定位时的 time，以及可选 note（规范化为空字符串）。标题最多200字符；每项备注最多10,000字符；最多2,000章，标题与备注合计最多1,000,000字符。ID 唯一，同一个 cue_id 最多一章；不同 cue 即使时间相同也可以分别设章。cue_id 接受现有文字稿合法的字符串，包括空字符串和长 ID；time 是有限非负数，不继承媒体时间书签的七天限制。未知项字段、重复锚点或非法值会拒绝整个导入，不会静默删章。

目录由完整 segments 的原始顺序派生，不按筛选后的列表、说话人分组或 time 排序。文本、说话人、翻译和时间修正保留同一 cue 的章节；定位使用当前 cue，保存的 time 保留建立时依据。缺失 cue 的章节仍保留标题、ID、时间和备注，显示“原位置不可用”，不会通过相似文字或最近时间猜位置。失效章可改名、删除或由用户明确重新定位；重新定位同时更新 cue_id 和 time。

创建、修改与删除章节均不修改正文或 readingPosition。章节导航不播放媒体，也不自动覆盖“读到这里”。返回跳转前位置是页面内临时导航状态，不增加第二个持久阅读位置。原声项目尚无文字稿、成果集也不是普通稿件，因此不接受章节数据。

## 导入、替换与备份

单稿 JSON、整库和选择书架备份均保留完整章节；重复恢复使用原有整文档去重，发生冲突时保留独立副本，章节仍属于其自己的稿件。导入 SRT/VTT 不会继承之前稿件的章节。真正替换全文时不得把旧稿章节偷偷复制到新稿；JSON 新稿只携带它明确保存的章节。导入恢复同一文档的缺失 cue 后，可按原 cue ID 重新解析，不关联其他稿件。

Markdown 阅读笔记包含手动章节目录、当时记录时间、当前文字稿时间或缺失提示，以及章节备注；它是阅读导出，不是可恢复备份。仅选定篇目的导出保留原有范围。章节标题不会生成媒体章节或替代原站目录。

## 旧版边界

已验证的上一版读者在同一浏览器的正常旧书架加载与保存路径中，会保留未知顶层 reading_chapters 字段，包括 legacy 和 IndexedDB 路径。这不等于所有旧版操作兼容。

旧版单稿 JSON 校验、书架备份导入/恢复会剥离它不认识的章节字段，之后再次保存不能恢复丢失的章节。请使用支持章节的版本进行导入、恢复和整理，并保留原始 JSON 备份。不要将旧版导入生成的文件当作完整章节备份。

## 核心接口

- normalizeReadingChapters(data)：校验并复制可选数组；不存在返回 undefined。
- readingChapters(doc)：返回 {item,cue,index,status}，有效章按完整稿顺序；失效项 cue 为 null、index 为 -1，稳定放在末尾。
- createReadingChapter(doc,{id,title,cueId,note})：返回新章节，不修改文稿。
- updateReadingChapter(doc,id,{title?,note?,cueId?})：返回修改后的章节，显式 cueId 才更新锚点及 time。
- readingChaptersWith(doc,item)：返回新增/替换后的已校验新数组。调用方赋给 reading_chapters 并使用现有文档保存队列。删除同样只过滤该数组。
