# 跨书架查找当前有效译文

## 使用

点侧栏或紧凑页头的「查找书架」，在宽幅面板顶部的「查找范围」选择「译文」，再输入记得的译文。侧栏原搜索框也可直接进入。辅助提示明确为「全部语言，仅当前有效的已存译文」。语言来自每篇已保存的翻译内容，与当前阅读语言无关。

- 每篇每个匹配语言显示一处译文预览、语言、源时间和原文上下文。每种语言独立使用「上一处 / 下一处」，所有匹配的起始片段均可到达。
- 同一语种同一起始片段中的重复出现合并为一个匹配片段；不同语言即使文字相同也分别保留。跨连续片段的短语仍标明跨段数，不把不同语言拼成短语。
- 点击选择相应双语语言，清除先前篇内筛选，显示准确的原文片段与译文匹配。长译文直接滚动到实际匹配文字。原有已存阅读位置不修改，媒体不自动 seek 或播放；跨篇开文仍遵守现有暂停策略。
- 没有搜索词时保留普通书架。标题、笔记、原文和历史摘录不会冒充当前译文匹配。原有「标题」「标题与笔记」「标题、原文、笔记与已存摘录」范围不改变；历史摘录中的译文只能按历史证据规则查看。
- 源文字、上下文、术语或人工核对依据变化后的旧译文排除。未保存的编辑草稿、缺失译文不参加搜索；搜索不会请求模型或网络服务。“当前有效”表示保存的依据未过期，不保证译文语义正确。

## 宽幅查找与返回

桌面面板宽度最多960px，并与视口保留48px余量；650px以下使用全屏和16px内边距。顶部固定关闭、搜索和范围；结果区单列、独立滚动。每篇仍只渲染有界预览，语言分组保留完整「第 n / N 处」和全部命中的上一处/下一处。每页40篇，上一页、下一页和直接页码跳转仍可使用。「筛选与排序」在结果区顶部展开；整理、移除与备份保留在普通书架工具里。

搜索框、范围、结果树、卡片缓存、页码控件都只有一份，在侧栏和面板之间移动。关闭、Escape、反复打开及650px两侧缩放不重建正文、不提交编辑草稿、不改变已存阅读位置、译文语言或播放器。搜索框的选择范围、输入法组合及原始输入节点保留。

选择有效命中后才关闭面板并沿用既有阅读导航。「返回书架结果」或重新打开入口可继续搜索词、范围、页码、每种语言的位置及实际结果焦点。取消后的最新页和控件优先于较早打开过的命中。返回以实际文档和命中证据的所有权为准；移除、同键替换和过期证据不会按旧ID猜位置。历史摘录切到现有笔记本查看，始终只开一个原生模态面板，关闭笔记本回原结果。

保存失败和受保护状态在搜索面板里显示原有提示与恢复控件。关闭或新的选择取消尚未完成的译文验证；晚到结果和关闭事件不会重新打开面板或抢回正文焦点。以上会话状态不写入备份或持久存储。

## 性能与所有权

沿用内存中的合作式短语索引、Unicode 偏移映射及完整快照发布，不增加持久索引或备份 schema。大书架、长文字稿及巨型单片段按既有调度器让出控制权；标题模式保留轻量路径。完成快照保存每语言预览引用与位置表，渲染仅当前40篇、每篇每语言一处。

源/译文变更仍须按既有 mutator 合约使搜索失效。激活时额外核对文档、片段、译文对象、保存文字、时间和所有跨段贡献者；共享证据表避免长重叠短语逐命中复制证据。跨128片段以上的激活验证让出主线程，新查询、离开当前阅读状态或新焦点会取消旧导航。发现未通知索引的内容变更时，拒绝旧命中并重建查找结果。保存冲突等禁止编辑状态会在离开书架前说明，不能静默切换或保存语言。

## 验证范围

CPU / happy-dom 回归见 `tests/reader-library-translations.test.mjs`：所有语言范围、来源/上下文过期、Unicode 跨段、同片段多语言、组内与书架分页、阅读位置、旧按钮/owner、晚结果、巨型字段与长验证取消。

真实浏览器旅程 `tests/library-translations-browser.mjs` 已接入既有 Browser acceptance Actions：实际文件导入、生产存储、译文与原文可视、真实媒体时钟/播放审计、桌面与390px键盘触达、44px目标、完整焦点环与五点无遮挡，以及长译文精确匹配定位。新增旅程须等待对应最终提交的 Actions 结果，不能把本地静态/DOM检查说成真实浏览器验收；没有在此云任务启动 Chromium/Electron，也没有调用真实模型或用户Mac。

宽幅状态回归见 `tests/reader-library-workspace.test.mjs`。`tests/wide-library-search-browser.mjs` 沿用现有 Actions，使用自写81篇及真实文件恢复/IndexedDB/媒体，验证1360px、390px和650↔651px布局、原生键盘与输入法、完整焦点环和五点无遮挡、页码与语言命中返回、历史摘录单面板、迟到激活取消、配额失败与重试。这里只说明验收范围；是否通过以最终精确提交的 Actions 为准。
