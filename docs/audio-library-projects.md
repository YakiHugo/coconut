# 无文字稿的原声项目

公开 RSS / 单集页或实际音视频直链查到媒体后，可点击「保存原声项目」。保存只写入当前浏览器书架，不下载音视频、不运行语音识别、不下载模型或使用订阅额度。点击「检查本集文字稿」后确认为没有可用定时文字稿的单集，也会保存为原声项目；节目简介不会变成原文。

- 项目包含来源地址、单集标识、媒体地址与类型、可选发布者时长，以及项目笔记和时间书签
- 原声项目明确显示尚无文字稿和摘要。用户笔记不充当原文，摘要、翻译、字幕导出不可用
- 「下载并回听本集原声」是单独操作，最多 200 MiB；播客来源仍按当前 RSS / 页面重新核验。直链沿用公开媒体验证与下载限制
- 可手动添加时间书签，也可从已加载播放器填入当前时间。书签笔记可编辑或删除，定位书签不会自动开始播放
- 来源、笔记与书签保存在当前站点的浏览器书架，刷新后可继续使用；媒体 Blob 不会持久化，刷新或重启后需明确重新获取，或选择对应本地文件
- 单项目 JSON 和整书架 JSON 都保留来源、笔记和书签。JSON 不包含音视频文件；不同来源页面/端口迁移要先导出再导入。Markdown 导出只用于阅读笔记，不能完整恢复
- 重复点击同一来源的「保存原声项目」会打开已有项目，不覆盖笔记；尚未有文字稿时，同时更新重新发现的来源、媒体地址、类型、时长和文字稿状态；已有文字稿保留其核对过的来源。媒体地址或类型变化时清除旧的发布者回听文件并取消旧下载，用户手动选择的本地文件仍保留。导入带不同修改的 JSON 则保留为另一份，整库恢复也不会覆盖不同版本
- 同一来源有多个备份版本时，必须在发现页明确选择目标项目，或选择「单独导入」保留另一份，不会默默选择第一份。
- 后续取得真正的定时文字稿时，可从发现页继续导入到同一个已解析项目，也可在原项目点击「为此项目补充文字稿」选择对应的 JSON / SRT / VTT；可使用高级服务已经完成的 ASR JSON。也可点击「检查并补充发布者文字稿」，重新取得本集明确关联的字幕。原项目标识、用户标题与明确修改过的语言、笔记、书签、收听位置和本次媒体保持连贯，不会另建重复项目。没有文字稿时保持原状，不自动识别
- 补充后，原笔记与书签仍以独立的用户记录显示，原文翻译与摘要只基于真正的文字稿。单项目和整库 JSON、Markdown 笔记导出都保留这些记录；再次保存同一公开来源不会把有文字稿的项目降回原声项目
- 本地文件需由用户核对确实对应当前声音。不会根据标题自动匹配；发布者入口核对准确订阅源、单集标识、媒体地址和类型；媒体变化时先停止，要求重新发现并核对，取消或切换项目后不会写入旧请求的结果

节目/订阅源提供的语言仅作提示。首次附加时优先采用实际文字稿声明的语言；只有用户在项目信息中明确改变过语言时才保留覆盖值，并随 JSON 和刷新保存。只改标题不会生成语言覆盖；明确清空语言会保留用户选择的「未标明」，不会被自动推断覆盖。没有明确覆盖记录的旧项目也优先使用文字稿语言。

发现页已经下载的预览原声在保存项目或导入文字稿时可直接交给阅读器，无需第二次下载。仅在单集、媒体 URL 和类型全部一致、且没有更新的媒体选择时转交；用户手动选的本地文件优先。转交只保留暂停的位置，不自动播放。新发现或预览清理不会撤销阅读器已接管的 Blob URL。详见 [发现页项目连续性](podcast-project-continuity.md)。

每个项目最多保存 100,000 字符项目笔记、2,000 个时间书签、每书签 10,000 字符笔记，全部笔记合计最多 1,000,000 字符。超限导入会拒绝，超限编辑保留修改前内容，不会截断；最大有效项目的 JSON 仍小于 15 MiB 单文件导入上限。保存空间不足或跨页面冲突仍会提示，须导出本页修改后再刷新。已保存的时间不代表已验证媒体内容；实际定位时会检查所选媒体的解码时长。

## 验证

- `npm test` 覆盖项目校验、无伪造原文/摘要、来源保存、重复保存、取消、书签增改删、刷新、单项目导出/导入、整库备份恢复及冲突版本
- `node tests/podcast-browser-acceptance.mjs` 使用原创合成音频与生产 HTTP 路由验证原声项目、显式重新获取、书签定位与 JSON 恢复，无公共网络或模型
- `node tests/podcast-live-browser.mjs` 在授权公共网络验收中使用实际公开音频一次，验证原声项目、笔记、播放时间书签、刷新与干净浏览器导入。真实来源有变化时会失败，不跳过为通过

- `node tests/project-continuity-browser.mjs` 将原声保存、补充文字稿、翻译/摘要请求范围、原声回听、笔记导出、单项目/整库干净浏览器恢复串成一条真实 Chromium 流程。发布者内容与模型响应均为明确注入的测试材料；该测试不能证明真实翻译/摘要质量，也没有运行 ASR

补充文字稿验证完整 JSON（含项目笔记与书签），大型 JSON 使用完整备份审核流程；15 MiB 是 SRT / VTT 字幕导入预算，不会用它截断或拒绝合法完整 JSON 备份。
