# 手动修正说话人标签

此功能修正已有的结构化 `segments[].speaker`。在逐句核对中可预览并修正当前原片段，或整篇与当前片段标签**完全相同**的所有原片段。大小写、内部空格及原标签首尾空格均参与精确匹配；新改名输入去掉首尾空白，空白输入不能提交；原标签原样提交保持不变（包括旧标签的首尾空格）。新标签最多1,000个 UTF-16 单元，与既有段落问答来源快照的说话人字段上限一致；超限明确报错而不截断。原有超长标签原样保持、读取及恢复不受新输入上限限制。筛选、分页和连贯阅读的视觉分段不缩小整篇范围。改成已有标签允许合并；这不会合并或重排原片段。

这不是自动说话人识别，不证明真实身份。不为缺少结构化标签的片段猜测人物，也不会替换正文中的 `[姓名]`。混合说话人的字幕正文仍原样保留。

## 来源与恢复

- 第一次真正改变标签时，另存 `original_speaker` 为修改前的完整结构化标签。未修改的片段没有这个字段，不补造历史。
- 后续改名不覆盖初始标签。恢复使用每个片段自身的初始标签；没有 `original_speaker` 的片段保持当前标签。
- 整篇同标签恢复可能把曾合并的标签拆回不同原标签，预览逐段显示实际目标。总数是范围内的片段数，修改数只计算标签实际变化的片段。
- 恢复后仍保留 `original_speaker`，再次修改仍能回到第一次修改前的标签。当前标签等于初始标签时已经恢复，不应显示仍被修正。此字段只记录一个来源基线，不是逐次操作历史。
- JSON 文档和书架备份保持该可选字段及原有 `schema_version: 1`。字段如存在，必须是非空白字符串；损坏的来源记录拒绝导入，不静默删除。旧文档的标签不增加长度限制，长标签不会截断。

只更改 `speaker` 和独立的 `original_speaker`。正文 `text`、正文来源 `original_text`、时间、ID、笔记、摘录及读到这里的位置不因此改写。恢复标签与恢复正文是两件独立的操作。

## 本地预览与提交契约

`Coconut.createSpeakerCorrectionPreview(doc, {cueId, scope, action, speaker})` 接受 `scope: 'cue' | 'speaker'` 与 `action: 'rename' | 'restore'`。默认是单片段改名；恢复不使用 `speaker` 参数。`SPEAKER_CORRECTION_LABEL_LIMIT` 暴露新输入的共享上限1,000，UI不得自行截断长标签。

返回冻结的 `{cueId, scope, action, fromSpeaker, toSpeaker, mixed, total, changedCount, preview, truncated}`。`preview` 最多8条，每条包含 `{id, start, end, text, fromSpeaker, toSpeaker}`；展示文字最多240个 UTF-16 单元且不会截断代理对。截短仅发生在预览，目标总数和提交范围保持完整。恢复时顶层 `toSpeaker` 为 `null`；每条的 `toSpeaker` 是其实际恢复标签。`mixed` 表示目标标签是否多于一种。

`Coconut.applySpeakerCorrectionPreview(doc, preview)` 验证预览仍属于原文档对象、选中标签与范围没有改变、所有目标仍在相同位置且预览与恢复依据未变：ID、时间、正文、当前标签，以及 `original_speaker` 的字段存在性和值。目标增加、消失、重排、这些依据变化，或者文档对象被替换，均要求重新预览。目标上的译文、译文历史、整段摘录标记或 `original_text` 更新，以及非目标片段的无关编辑、文档笔记及阅读位置变化不被覆盖，也不阻塞提交。提交从当前 cue 浅拷贝保留这些最新数据。预览直接保留所需字段的值，不序列化整个 cue，也不遍历无关译文或历史，避免每次标签输入复制大量旧数据。改名后恢复原样也不能复用更早的预览；预览不能跨 JSON 序列化传递或再次提交。

成功提交同步构造新片段数组并仅赋值一次，返回 `{changed, changedCount, cueIds}`。无变化返回 `changed: false`，不写字段、不替换数组。取消仅丢弃预览，不写文档。UI 只在实际变化时触发既有保存管线；保存失败仍保留当前页修改，可重试或导出未保存 JSON 备份，不能把内存更新称为持久保存成功。

## 历史依据与导出

- 带说话人上下文的译文、人工核对依据，以及保存了说话人上下文的段落问答，按既有快照规则显示过期。历史记录本身不重写，也不自动调用模型。
- 普通仅依赖正文的旧译文、普通问答、整篇摘要及其待续分批任务不会仅因标签变化被强制过期；它们的请求原文只含 ID 与文本。
- 精确摘录仍使用既有摘录 schema，保留摘录时的旧标签。来源状态会过期，快照字节保持不变；还原所有相关来源后可重新显示一致。独立 `original_speaker` 不加入摘录快照。
- 连贯阅读分段、正文文本导出、阅读笔记和 VTT 使用当前标签。VTT 正确转义标签；SRT 不写说话人标记。JSON 保留当前标签和来源基线。

## 验证边界

核心纯函数测试覆盖单段、整组、合并与混合恢复、无变化、取消、空白输入、损坏来源、文档替换、过期/重复预览、目标增减/重排/修改、非目标编辑、160个匹配片段跨分页范围、JSON/书架往返、摘录快照不变、依赖过期规则及导出。均为本地自写数据，无真实浏览器、音视频识别、账户模型或网络验证。
