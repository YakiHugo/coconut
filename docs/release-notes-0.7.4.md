# Coconut 0.7.4 · macOS 开发版

本轮桌面目标版本为 0.7.4。以下为本版本源码的改进；实际发布与下载以 GitHub Releases 为准，本文不表示构建、验收或发布已完成。v0.7.3 下载包不包含以下新增功能。

## 相比 0.7.3 的改进

- Cmd+F / Ctrl+F 直接打开当前文字稿查找，macOS 原生「编辑」菜单也可调用；选中已有查找词，不改写阅读标记或启动播放。编辑框、弹窗等受保护场景不被接管。
- 选中同一段落内的连续原文后，可「保存所选摘录」。笔记本保留当时的文字、标题、来源、字幕时间范围及上下文；后续修正或删除原文不会改写这份历史快照。可查找、移除、导出，完整 JSON 备份可保存它。
- 可导出整篇 TXT，按阅读段落组织，而非只导出当前页或搜索结果。可附加当前显示语言的有效译文；缺失和过期译文会明确标注，过期内容不会混入导出。

- 笔记与摘录列表收起时显示简短预览，展开后只显示一份完整引文；历史来源、个人笔记、上下文和技术信息分层呈现，不裁剪保存或导出的内容。
- 同一处理任务恢复原声后，继续使用已有阅读条目并保留批注；不自动播放、不替换用户选定的本地媒体，也不抢走当前阅读或编辑位置。
- 连贯阅读的每段可直接点击「读到这里」，把手动阅读标记设在本段开头；明确显示待保存或保存失败，支持现有重试与恢复流程，保存本身不触发滚动。修复 Tab／Shift+Tab 键盘导航时段落操作及焦点边框被固定提示区或播放栏遮挡的问题。
- 没有已存摘要或摘要任务的短稿，打开后直接进入原文；已有摘要仍可继续查看。重开示例直接进入正文并保留原文／双语选择。

以上阅读、查找、查看历史和复制操作不调用模型；保存摘录、TXT 导出及阅读入口切换也不调用模型。既有功能见 [0.7.3 历史发布说明](release-notes-0.7.3.md)。

## 使用边界

精确摘录只支持一个显示段落中的连续原文；时间精度到原字幕片段，不是逐词对齐。来源变动会明确区分历史引文与当前原文；原片段缺失、重排或不再连续时，不猜测跳转位置。保存成功以实际持久化回执为准。

TXT 用于阅读分享，Markdown 用于笔记整理，二者和 SRT/VTT 都不能替代完整 JSON 备份。导出不会生成新译文；下载提示只表示已发起下载，请确认文件实际保存。

同任务原声恢复只会自动关联已有本地任务绑定的阅读条目。升级前已编辑且未绑定的旧条目不会按相似文字猜配；普通 JSON 备份不恢复该本地绑定，不能据此恢复原任务关联。

## 升级、备份与恢复

升级前导出并确认保存「备份整个书架」的完整 JSON；升级后有新修改时，再导出新版备份。备份不包含音视频文件、账户登录或未提交的编辑草稿。

精确摘录是可选的 exact_excerpts 字段，不是数据库版本迁移。旧版 JSON 导入／书架恢复会丢弃不认识的该字段；请使用支持精确摘录的版本恢复，并保留未经旧版处理的原始 JSON。旧版不支持这些摘录的查看和管理，不能据普通加载／保存可能保留未知字段推断完整降级兼容。既有不含该字段的备份保持原有行为；无效或不支持的精确摘录记录会被拒绝，不会静默丢弃。

书架继续使用 IndexedDB。旧 localStorage 快照不会同步新版修改，v0.6.0 无法读取新版新增或修改的内容。不要在旧版继续编辑同一资料库，也不要为了重试而清空存储；原始技术恢复文件不能直接当作普通书架备份导入。普通恢复跳过相同内容，分别保留不同修改版本。超过 50 MiB 的 JSON 先确认再读，不代表无限容量；SRT/VTT 仍限单文件 15 MiB。

保存失败时，使用「导出未保存文档备份」保留本窗口所有待保存内容并确认落盘；未提交表单草稿需另行保留，再关闭或刷新。过期写入不会覆盖较新文档，其他独立文档仍可自动保存，全局未保存警告与关闭保护继续有效。
