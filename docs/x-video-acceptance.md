## 尚不能宣称完成

- 平台字幕含需人工核对的专有名词和识别问题，没有完整人工逐字听校
- 作者发布的章节主题与字幕中实际主题位置有偏移；阅读笔记按字幕自身时间定位，未把作者目录当作精确转录时间
- 真实结果的阅读测试为自动化 DOM 测试，不是完整的交互式浏览器视觉验收
- 本环境此前的 localhost 浏览器导航、文件选择/下载受限；未通过公开托管私有稿件、隧道或修改权限来绕过限制
- 导出验证确认了 JSON 内容及重新导入；没有把浏览器触发下载等同于已成功保存到用户磁盘
