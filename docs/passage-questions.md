# 问这一段

连贯阅读的每个段落，在「回听这一段」「逐句核对」旁提供「问这一段」。它打开一个原文优先的对话框，复用既有 AI 请求表单与阅读历史；没有另一个后端、队列或自动请求入口。

## 可见的范围和确认

- 初始范围仅含点击段落中的原字幕片段，保留源顺序、ID 和修正后原文。一个 120 片段文档中的 6 片段段落只发送这 6 个片段。阅读搜索、笔记、摘录和译文筛选不会暗中扩大或缩小这个范围。
- 预览逐个显示完整原文、请求时的起止秒数与说话人，并显示来源标题、地址和原片段总数。文字不是译文或笔记，也不是生成的摘要。
- 「加入前后各一段原文（如有）」必须明确勾选。预览、范围计数和上下文标签立即更新，原有同意失效。取消勾选回到原段落；没有自动扩展。
- 可以编辑问题、选择已有的 Codex / Claude 提供商和回答语言。检查连接不会发送原文。问题、提供商、语言或范围变化后必须重新确认。
- 只有勾选本次发送同意并点击「发送问题」才会 POST 既有 `api/ask`。请求仍为最小原文 `{id,text}` 列表；时间、说话人和来源元数据只在本机保留作为依据。原片段的 ID 是引用单位，模型可能引用其中一部分。
- 超过既有单次请求大小限制会阻止发送；不会自动改用全文、另一个提供商或付费 API。

## 中断、返回和保存

Escape 或「返回阅读」关闭对话框，将同一个表单与历史归还原位，并保留输入文字。从段落打开时返回同一段落的操作按钮；从历史引用打开时返回原文位置。移动端沿用原生可滚动对话框，段落操作和对话框按钮至少 44 px；没有新增常驻顶部工具栏。

引用进入对应原片段。「返回段落提问」恢复捕获的确切范围和当前问题草稿，永远不恢复先前同意。保存的回答也可在重新导入或刷新后查看当时完整原文、来源、秒数、说话人、所选提供商和回答语言。移除的引用显示不可用，不能伪造导航。原文、时间、说话人、来源、语言或标题变化时，历史依据显示过期；准备中的请求需明确重新核对。

Escape、返回阅读、引用核对或普通切篇只关闭提问界面，已发送的一次请求仍可保存到其确切、未变更的原文档；不会重新打开对话框、切回文档或抢走焦点。未完成前不能再次发送。改变准备中的上下文、问题或提供商也不改动已发送请求。明确点击「取消接收本次回答」、原文依据失效、移除或替换文档、离页、成功锁定原生退出会退休请求，迟到结果不再保存。已发出的请求仍可能消耗额度，取消接收不能退款或保证终止远端处理。新增答案沿用现有保存回执；失败时保留当前页结果并提示 JSON 备份，不冒称已保存。

## 持久化兼容性

旧 `input_snapshot: {version:1,segments:[{id,text}]}` 保持兼容。段落问答另有可选 `scope`：

- `kind: "passage"`、原段落 `passage_ids`、`expanded`
- `source_title`、`source_url`、`source_language`
- 请求时选择的 `provider`、`answer_language`
- 与发送列表逐项对应的 `cues: [{id,start,end,speaker}]`

范围最多为原段落及前后各一段，最多 48 个片段；原段落本身最多 16 个，超长单个片段不被拆开。清理器拒绝错序、重复、缺失、无效时间或不匹配的范围元数据；不能把破损依据悄悄当作当前有效的记录。JSON 备份完整保留范围，Markdown 导出同时列出历史原文与请求时定位依据。现有整篇摘要及普通筛选提问不改变语义。

## 验证及边界

`tests/reader-passage-question.test.mjs` 使用原创 120 片段数据与注入回答，覆盖 6 片段默认范围、显式相邻扩展、确认失效、来源修改、回到引用、备份恢复、Escape、迟到响应、移除、离页和原生退出。现有 AI 动作、历史、译文、段落阅读和存储回归同时保留。

`tests/passage-question-browser.mjs` 已加入 Browser acceptance CI。该旅程用本地 Node bridge 与注入提供商，检查桌面/移动端实际键盘、44 px 目标、350 px 首屏原文预算、对话框几何、精确请求、引用返回、真实 JSON 下载及干净浏览器恢复。它不使用真实模型或账户。

本次受限云工作区只运行 Node/HappyDOM、Python 与语法检查；未启动浏览器或 Electron。新增旅程的真实浏览器通过证明仍待 CI，不应以语法检查或 HappyDOM 冒充。没有真实模型质量、订阅额度或原生安装包运行证明。页面未添加新运行时脚本，既有脚本继续由 Python/Node 静态路由与桌面资源分发清单提供。
