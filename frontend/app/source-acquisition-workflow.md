# 来源获取与文字稿处理

打开公开播客单集或支持的单视频链接后，Coconut 创建或复用对应项目并打开阅读页。节目主页和 RSS 列表保留单集选择。服务端分别保存原声下载和作者字幕检查任务，页面关闭后任务继续。

- 原声下载显示实际字节数。来源声明可信总大小时显示百分比，最后校验文件并保存。播放器在原声就绪后自动载入。视频的自动获取选择独立音轨。
- 作者字幕检查仅导入发布者提供、通过来源和时间轴校验的字幕。需要选择语言时只暂停该分支。访问失败、格式不支持和作者明确未提供字幕分别显示，下载独立进行。
- 确认作者未提供字幕、已保存原声且本机转写配置就绪时，服务端自动启动本地识别。模型和引擎沿用当前配置。未能确认字幕状态时，用户仍可明确发起本地转写。
- 作者字幕和转写结果写入原声项目时，服务检查来源绑定和书架版本。已有稿对齐检查原稿和对应的音频摘要。各分支保留失败状态和独立重试入口。
- 文字稿保存后运行本地口语精简和断句。来源与整理中的文字整理提供对齐、标点、说话人和 CLI 校对。已存原声由本机服务直接读取。CLI 操作需要确认发送范围和额度。
- 阅读页通过同源事件流接收进度、原声就绪和书架更新。事件流连接或恢复时核对当前任务，断线时低频拉取。服务端保存任务和书架版本，客户端保留用户当前的保存操作。

只有支持持久来源任务的服务才能运行完整流程。视频自动获取依赖支持原声和作者字幕检查的助手。静态页面和轻量服务可导入已有字幕。已知来源有公开媒体直链却未声明字幕状态时，显示字幕信息未知并保留手动开始本地转写的入口。
