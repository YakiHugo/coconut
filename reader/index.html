连接本地 AI 工具与高级处理

轻量方式，不需要 Python

Web 可直接导入文字稿、选择本地音频或视频同步回听。生成摘要或订阅翻译时，使用 Coconut macOS 开发版，或在源码目录运行 npm run start:light（开发者需 Node.js 22+）。然后使用官方 Codex / Claude Code CLI 登录已有订阅，每次发送前确认原文范围与额度。当前 macOS 构建未经签名公证，不是已验证的正式安装版。

公开 Web 不会连接或探测你电脑上的 CLI；请打开桌面应用或轻量服务显示的本地页面。

轻量服务、macOS 构建与 CLI 连接说明
高级方式：视频下载、ASR 与离线模型
  1. macOS / Linux 需要 Python 3.10 或更新版本（已测试 3.12）和 Git。视频下载与提取还需要 ffmpeg。
  2. 在终端依次运行下面的命令。安装会下载依赖，只在项目目录创建虚拟环境，不修改 shell 配置。 
    git clone https://github.com/YakiHugo/coconut.git
cd coconut
./install.sh
./coconut
  3. 保持终端运行，在浏览器打开终端显示的本地地址（默认 http://127.0.0.1:8080），然后粘贴视频链接或导入音视频。公开预览不会自动连接这个服务。

已经安装？在原项目目录运行 ./coconut 即可。端口被占用时可运行 ./coconut --port 8081，并打开终端显示的新地址。关闭终端会停止处理；重启后可重试中断任务。

公开预览和本地地址的书架互不相通。先在原页面导出文字稿与笔记，再到新地址导入；备份不包含视频文件。更换端口也需要这一步。

默认仅使用现成字幕，没有匹配字幕时会停止。只有在处理选项取消「仅使用现成字幕」后，才允许本地识别，首次可能下载模型。离线翻译另需语言模型；AI 订阅需本机官方 CLI 已登录，并逐次确认发送文字与使用额度。
